## 0. 这份草稿是什么

2026-11-15 凌晨群里（与「遗迹之羽」）讨论左海市主角团的产物。整理成五人，按本 wiki 的角色模板节次摆，缺的地方留「待定」，等拍板。

方法论上认了对方两条：一是先给每个角色定成长路线，再按路线安排事件，不要倒过来先想他们干了什么；二是世界观越大越要写群像，主角团人人都算主角，大环境推着事件走，事件逼角色做选择，变化才立得住。

## 1. 共通背景（五人共用的那部分）

- 1999 千禧陆沉之后，左海市重建、扩张，民间对「那年的事」只剩下传说。
- 2012 年：左海市港口脏弹引爆，扭曲怪物入城。同一时期，边境发生袭击，多人失踪。事后「帷幕计划」把非凡信息彻底封进帷幕之内。
- 律法的通行设定沿用本 wiki：因强烈情感而扭曲现实，碎片守恒，非凡存在天然互相吸引。名号与律法可继承。
- 官方三线：左海市现世安全局（地方）、暴恐机动队（直属中央，需地方请求才可出动）、新神州一百零八禁军（三十六天罡／七十二地煞，领星名）。
- 民间一线：白泽事务所，依《新神州术士管理条例》注册，明面接外包刷声望，暗面查 2012 真相。

## 2. 白泽（所长）

| 项 | 内容 |
|---|---|
| **姓名 / 常用称呼** | 待定；所内称「所长」，外人称白泽 |
| **种族** | 奇幻种·白泽（纯血） |
| **年龄 / 所属时代** | 与主角相仿，第一章二十上下；联合国解体后 |
| **出身** | 现世·新神州·左海市 |
| **所属势力** | 白泽事务所（自建） |
| **位阶** | 待定（建议 4–5 阶，形成界入门，人格稳定「中」） |
| **律法** | 待定名；权能：读心——持续接收周围一切信息。边界：读不到主角（他对外近乎信息真空）。代价：信息过量冲刷自身的认知 |
| **帷幕内外** | 合法术士；帷幕之外「维护」；凡人面前是普通事务所老板 |

- 性格：克制、要强、不肯示弱。嘴上冷，行动上极护短。
- 母亲是主角前监护人的队友，2012 年边境袭击中一同失踪。父亲凭白泽的信息处理能力在袭击后上位，现为左海市现世安全局局长，父女互不理解。
- 父亲不许她以官方身份查案，她便自建事务所；给父亲那边接外包，暗地查自己的。
- 小时候读不到主角的信息，所以常往对门跑；2012 年后被帷幕隔在两个世界，第一章两条线重新交叉。
- 成长路线：把主角当成需要看管的遗物 → 被迫承认他的判断 → 发现父亲／局内与真相有关，世界观塌一次 → 不再用「继承者的守护者」定义自己。

## 3. 主角

| 项 | 内容 |
|---|---|
| **姓名 / 常用称呼** | 待定 |
| **种族** | 人类（超凡信息感知近乎为零，成因待定） |
| **年龄** | 二十上下 |
| **所属势力** | 白泽事务所 |
| **位阶** | 待定（能力来自继承，不是自己修上来的） |
| **律法** | 继承前监护人的律法与名号；名称与权能待定 |

- 前监护人在 2012 年边境袭击中失踪，留下名号与律法。帷幕计划把他隔在非凡世界之外，第一章才被拉进来。
- 动机：弄清交到手里的东西是什么；回答「借来的翅膀究竟能飞多高」；找到大姐姐下落。
- 成长路线：拖油瓶（自己也不信）→ 在一次次选择里赢下信任 → 知道律法的真相（或许继承来的东西本身有问题）→ 不靠继承的名号立身。
- 参考：《装甲核心 6》621 与卡菈，态度从轻视到看重。

## 4. 落魄公子哥

| 项 | 内容 |
|---|---|
| **姓名 / 常用称呼** | 待定 |
| **种族** | 人类（普通术士或纯凡人，待定） |

| **律法 / 位阶** | 待定；若定「无律法」，则他在队里承担「凡人视角」 |

- 2012 年他家公司所属港口被炸，家破人亡。官方声明与企业无关，民间舆论却认定他家该负责。
- 为查真相加入白泽事务所。队里唯一懂「钱与舆论怎么运作」的人，也是把「民间的怀疑」带进主线的那条线。
- 成长路线：想洗清家名 → 发现清白换不回人 → 改为追那个真正该负责的东西。
- 感情线：与游方术士。

## 5. 重甲龙娘

| 项 | 内容 |
|---|---|
| **姓名 / 常用称呼** | 待定；前期不露面，队内以代号称 |
| **种族** | 龙裔 |
| **所属势力** | 左海暴恐机动队总教官；实为上层派来的特派员 |
| **位阶** | 待定（建议 6 阶上下，人格稳定「中」偏「低」） |
| **律法** | 待定；与「重甲」相关的防御／压制型权能 |

- 2012 年袭击后被调来训练左海本地对非凡武装。暴恐机动队调动权限直属中央，没有当地安全局的支援请求便不能出动，于是她暗中联系成绩最好的非凡者组织白泽事务所替她查非凡犯罪。
- 训练是副业，主职是搜集信息、挖出现世安全局里的内鬼。本质是刷晋升，目标新神州一百零八禁军，将从三十六天罡七十二地煞里领一个星名。
- 形象：前期神秘老大哥做派，不着装时才知是龙娘。参考「泥岩」。
- 成长路线：旁观者／考官 → 被左海这摊事卷成当事人 → 放弃晋级赛名额去换一个真相 → 真正站队。

## 6. 游方术士（福利院出身）

| 项 | 内容 |
|---|---|
| **姓名 / 常用称呼** | 待定；队里叫「大夫」或外号 |
| **种族** | 人类 |
| **年龄** | 二十出头 |
| **所属势力** | 无照游方术士 → 被白泽事务所收编 |
| **位阶** | 待定（建议 2–3 阶，物质界） |
| **律法** | 生理治疗：直接治愈伤损，不依赖药物。边界待定。代价二选一：治愈时自己承受同等疼痛／每次使用损耗一段自身记忆 |

- 出身：1999 年灾难后失去双亲，福利院长大，院里孩子的大师姐。
- 卖「灵丹妙药」（优乐美泡水）却能治好病，赚的钱捐给新神州儿童医疗，被逮到时身上只有五十块，收编以打工抵违法所得。
- 2012 年动乱：港口脏弹催生的扭曲怪物入城，把福利院抹平。那天她与院长出门进货，回来只看到尸山血海；院长临死教了她两手开车，自己冲上去同归于尽。此后她不会开车，见不得开车的人，队里叫「载具杀手」。
- 性格：外热内冷，话多，心里有很硬的一块。队里最会照顾人，也是唯一敢跟白泽顶嘴的。
- 伏笔：心里一直有个「老院长」和她说话。等她能独当一面那天才发现，老院长早就死了，留在她脑子里的是自己记忆长出来的那一个——接「律法因强烈情感影响现实」。
- 成长路线：靠小把戏救人、躲着官方跑 → 被收编，第一次有「组织」 → 老院长的真相，她的「治疗」其实靠自己硬撑 → 治好自己那一次，然后真的能开一次车。
- 感情线：与落魄公子哥。

## 7. 待决断

1. **第一章事件**：还没定。定了之后倒推五人各自的进场方式（按遗迹之羽的方法：先路线后事件）。
2. **律法的具体规则**：怎么继承、什么条件失效、名号与律法谁依附谁。「借来的翅膀」这个主题要靠它落地。
3. **主角为什么是信息真空**：是天赋、是前监护人做的手脚、还是律法本身的性质。这条直接决定白泽读不到他的意义。
4. **游方术士的代价**：选「承受疼痛」还是「损耗记忆」，两者对后面那把刀的手感不一样。
5. **公子哥是否持有律法**：持有一条，队里就多一个战斗单位；不持，他就是全队的凡人视角和舆论线。
6. **龙娘的星名**：天罡还是地煞，哪一个星，决定她后期的定位。
7. **底层到高层的人物谱**：官方、企业、民间三线各至少补两人，群像才撑得住。

**原文**

【源质反应堆】

源质反应堆是针对终末之环进行逆向工程的产物。

它只拥有了与终末之环近似燃烧源质以稳定深度的功能，可功效却不及终末之环的哪怕百分之一。

源质反应堆并不能像终末之环那样燃烧整个现世范围内的源质，而是根据不同机组规模拥有街区、城市、行省、国家这四种级别的范围。

源质反应堆也无法像终末之环那样自行从现世、旧域与边境内抽取源质，在无需任何外部能源供应的情况下永久运行，源质反应堆的运行需要以辉石为燃料。

当终末之环在千禧陆沉事件中消失、现世内部深度平衡因源质浓度激增而濒临崩溃时，规模不同的源质反应堆们便成为了维持现世稳定的临时措施。

可现世内部辉石的储量是有限的，一旦辉石储量耗尽，现世就将因深度平衡的崩溃而死去。

## 源质反应堆的特征

**它是终末之环的仿制品：以[辉石](源质.md)为燃料，烧掉当地的源质，把一块区域的[深度](深度体系.md)维持为正。**

## 源质反应堆的运作原理

```
投入：辉石（燃料）
  └─► 燃烧该区域内的源质
        └─► 源质反应程度变低、深度稳定为正值
              └─► ① 低源质环境 —— 限制术士在现世内部的活动
```

## 与终末之环间的区别

| | [终末之环](封印物.md)（原件） | 源质反应堆（仿制品） |
|---|---|---|
| 燃料 | 无需外部能源，**自行**从现世／旧域／边境抽源质 | **需以[辉石](源质.md)为燃料** |
| 燃烧范围 | **整个现世** | 仅**区域**级：街区／城市／行省／国家 |
| 功效 | 基准 | **不及终末之环的百分之一** |
| 现况 | 1999 年后沉入[旧域](四层世界.md#旧域) | 现世稳定所依赖的**临时措施** |

## 源质反应堆的重要性

千禧陆沉让终末之环沉入旧域，现世内部的源质浓度只增不减，深度平衡濒临崩溃。**不同规模的源质反应堆顶了上来，成为维持现世稳定的临时措施。**

但这是**倒计时**：

> **现世的辉石储量有限。一旦耗尽，现世就将因深度平衡的崩溃而死去。**

**原文**

> **轮回终末**同样拥有**代行者**，祂引发了**第一次冲击**，令高天之上的烈火降临于世、将第五纪元的可能性自**原初律法**中解放，就此阻止**无上意志**支配万物的进程，成为第五纪元的**无名之王**。

> 原文出处：[外神](外神.md) 的「代行者体系」一节。原文只说「成为」——**是谁坐上了那个位子，原文尚未点名**。

## 无名之王

**律与威权之主，不受[无上意志](外神.md)束缚的第五旧王。**

| 项 | 内容 |
|---|---|
| **身份** | [轮回终末](外神.md)的**代行者** |
| **称号** | 律与威权之主 |
| **立场** | **不受无上意志束缚**——与四位[旧王](旧王.md)分属对立的一侧 |
| **作为** | 引发[第一次冲击](破碎战争.md)，将第五纪元的可能性自[原初律法](律法.md)中解放，阻止无上意志支配万物的进程 |

## 在代行者体系中的位置

| 外神 | 等级 | 代行者 |
|---|---|---|
| [无上意志](外神.md) | 上位 | [旧王](旧王.md)（四位） |
| [轮回终末](外神.md) | 上位 | **无名之王** |
| [绛天之龙](外神.md) | 次位 | [古龙](天灾.md) |
| [铸形之炎](外神.md) | 次位 | [灰风](天灾.md) |
| [伏行之恶](外神.md) | 次位 | [神孽](天灾.md) |

外神本身仅遵循本能、不直接干预世界；**代行者就是祂们的意志落进世界的方式**。轮回终末的本能是**不再受任何存在制约的绝对混沌**，由此出发，祂的代行者所做的事只有一件：

- **打断无上意志的进程**——把第五纪元的可能性自[原初律法](律法.md)中解放，令「一切可能性都将不复存在」无法实现。

## 两条锋刃的对立

| | [无上意志](外神.md) | [轮回终末](外神.md) |
|---|---|---|
| 本能 | 以自身意志支配万物的**绝对秩序** | 不受任何存在制约的**绝对混沌** |
| 代行者 | 四位[旧王](旧王.md) | **无名之王** |
| 代行者的目标 | 将现世与边境彻底沉入[旧域](四层世界.md#旧域)，复现[原初律法](律法.md) | 破除一切固有规则，阻止前者实现 |

> 两者的取向**在本能层面上绝对对立**，权能却**都对世界有正面意义**——故相互制衡，造就了世界的[往复轮回](世界往复.md)。

## 第五旧王的位子

[黄金时代](历史概述.md)的原文明记录里留着一句：一旦原初律法彻底完善，**世界便将死去，而第五位旧王将于世界的废墟中加冕**。

| 项 | 内容 |
|---|---|
| **预言** | 第五位[旧王](旧王.md)于世界的废墟中加冕 |
| **实际发生的事** | [破碎战争](破碎战争.md)末期，[终末之环](终末之环.md)被迫提前点火 → 「[第一次冲击](破碎战争.md)」降临，[原初律法](律法.md)分崩离析，前文明毁灭，「[新世](新世工程.md)」工程取得惨烈的成功 |
| **结果** | 世界没有以「律法彻底完善」的方式死去；轮回终末的代行者**成为第五纪元的无名之王** |
| **与四位旧王的关系** | 同为上位外神的代行者，但**分属对立的一侧**；不受无上意志束缚 |

## 尚未展开

- **「律与威权」的具体所指**——这一称号对应的权能范围。
- **「不受无上意志束缚」的机制**——与其他代行者的根本差异落在何处。
- **无名之王的行踪**——四位旧王在[旧域](四层世界.md#旧域)深处恢复、由附属势力代为活动；无名之王在第五纪元中的动向，原文未提。
- **与第五纪元纷争的关系**——[历史概述](历史概述.md)写第五纪元「那些执掌律法的存在逐渐成为这个时代的主角，新一轮的纷争正在历史的暗面中涌动」；无名之王在这场纷争里站在哪一边、是否参与，原文未提。
- **祂是否拥有衍生势力**——四位旧王各有衍生势力（[百相熔炉 / 世外天国 / 永世集团 / 黄金黎明](旧王.md)），无名之王没有记录。

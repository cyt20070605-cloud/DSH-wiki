## 黄金时代

**原文**

【黄金时代】

世界自烧却混沌的烈火中诞生，又将在终结万物的旧域中死去。

在如此往复中，时间进入了第五纪元。

四位诞生于死去世界的“旧王”开始行走于世间，受祂们注视的存在拥有了轻易扭曲现实的权能，前文明因此迈入了极尽繁荣的黄金时代。

可使用这份权能的代价，却沉重到令人无法想象。

随着那些扭曲现实权能被滥用，源自旧域的“原初律法”正在侵蚀现实，一旦其彻底完善，世界便将死去，而第五位旧王将于世界的废墟中加冕。

前文明不愿坐以待毙，他们决意燃烧万物以延续未来，以名为“终末之环”的至高造物为核心，更新世界的“新世”工程就此展开。

### 新世工程

> **前文明不愿坐以待毙，他们选择将自身化作更新世界的锋芒。**

| 项 | 内容 |
|---|---|
| **概括说法** | **更新世界**——这是原文对工程的概括 |
| **最终产物** | [终末之环](终末之环.md)——工程所造出的最终产物；破碎战争末期**尚未完成**、被迫提前点火 |
| **手段** | 以终末之环**燃烧[源质](源质.md)**的能力 |
| **先行阶段** | **燃烧源质**与**摧毁「原初律法」**同属**先行阶段**，不是工程的终点 |
| **最终目的** | 创造「**新世**」——一个**凌驾于此方世界之上**、**永诀律法**的世界 |

> **「更新世界」不等于工程的全部。** 燃烧源质与摧毁原初律法都只是先行阶段；工程真正要创造的，是那个永诀律法的世界。

**它篡夺了什么**：工程的矛头不止对准律法，也**对准了创世者本人**。「高天之上的烈火」即**创立世界**的上位外神「[轮回终末](外神.md)」的烈火——与「烧却混沌的烈火」**同一物**。工程**引动高天之上的烈火**降临于世，**篡夺的正是这位创世者的权能**——这正是[世界往复](世界往复.md)的**本轮被打破**之处。

**后果**：以前文明的毁灭为代价，「[原初律法](律法.md)」**分崩离析**，**一切可能性被从[无上意志](外神.md)手中解放**；「新世」的**存在被确定**，只是**如今尚未降临**。终末之环是被迫提前点火的**半成品**——工程**未能完成**，这一点**从未被修复**。

## 破碎战争与第一次冲击

**原文**

【破碎战争】与第一次冲击

作为前文明“新世工程”的最终产物，终末之环拥有着燃烧源质的恐怖威能，它的存在令旧域中一切以源质构成的存在都面临前所未有的威胁。

于是，“破碎战争”就此爆发。

在“破碎战争”末期，面对早已无力回天的现实，尚未完成的“终末之环”被迫提前点火，不受控制的链式反应撕裂了维度间的界限，引动高天之上的烈火降临于世。

“第一次冲击”随之降临。

以前文明的毁灭为代价，“原初律法”分崩离析，世间的一切可能性得到解放，“新世”工程取得了惨烈的成功。

可动荡的第五纪元却仍在延续，以区域内物理规则稳定程度为判定标准，现世、边境与旧域的划分随之出现，那些执掌律法的存在逐渐成为这个时代的主角。

为了争夺第五纪元那唯一的王位，新一轮的纷争正在历史的暗面中涌动。

### 第一次冲击

| **结果** | 「[新世](时间线.md#新世工程)」工程取得**惨烈的成功**——「新世」的**存在被确定**，只是**如今尚未降临** |
| **世界的形状** | **动荡的第五纪元仍在延续**；[现世](四层世界.md#现世)、[边境](四层世界.md#边境)与[旧域](四层世界.md#旧域)的划分随之出现 |
| **时代主角** | **执掌律法的存在**逐渐成为这个时代的主角 |
| **伏笔** | 为争夺**那唯一的王位**，新一轮的纷争正在**历史的暗面**中涌动 |

**它留下的东西**：这场战争是此后一切非凡格局的起点。

| **[奇幻种](奇幻种.md)** | 战后祖先因**接触破碎的原初律法**而产生突变，各不相同的律法随**血脉**流传至今 |

## 神话时代

**原文**

【神话时代】

在“第一次冲击”后，过往的一切历史被旧王扭曲，旧世界的幸存者们开始为争夺拥有扭曲现实权能的律法碎片而进行着残酷的厮杀。

最终的胜利者成为了现世最初的“神明”，祂们成功在旧世界的废墟上建立了最初的秩序，原始非凡体系就此诞生，人们向神明献上信仰，以此换取通往非凡的资格。


## 震怒之日与第二次冲击

**原文**

【震怒之日】与第二次冲击

神话时代末期，现世的诸神沉沦于律法所带来的无上威权，为了重塑传说中的原初律法，祂们发动着永无止境的神战。

在漫长的动荡与纷争中，散落各界的律法碎片被不断收集并重塑，现世的深度也随着物理规则的失衡而持续降低。

某一日，现世的深度正式归0，祂们最终唤起了旧域深处旧王们的注视。

在这场被后世称为“震怒之日”的事件中，“第二次冲击”降临，曾经终结混沌的神明尽数陨落，神话时代就此结束。

### 震怒之日

| 项 | 内容 |
|---|---|
| **时间** | **十四世纪末**（神话时代末期） |
| **起因** | 诸神**沉沦于律法所带来的无上威权**，为**重塑[原初律法](律法.md)**发动**无止境的神战** |
| **过程** | 散落各界的**律法碎片被不断收集并重塑**；[现世](四层世界.md#现世)的[深度](深度体系.md)**随着物理规则的失衡而持续降低** |
| **触发** | 某一日，现世的深度**正式归 0**，**唤起了[旧域](四层世界.md#旧域)深处旧王们的注视** |
| **结果** | 「**第二次冲击**」降临；**曾经终结混沌的神明尽数陨落**，**神话时代就此结束** |

> **为什么叫「震怒之日」**：这是**后世**对这场事件的称呼——它不是某一场战役，而是**整个诸神神战失控、以第二次冲击收场**的那段时期。

**它改变了什么**

| 变化 | 说明 |
|---|---|
| **神明的退场** | [神明](神明.md)——终结混沌者——**尽数陨落**；神话时代结束 |
| **非凡途径的解放** | 通往非凡的路径**从信仰中得到解放**；在信仰还是唯一通路的时代，执掌律法的强者自然被当作神，此后这类存在换了个更中性的名字 |
| **[深度](深度体系.md)跨过零点** | 现世的深度**正式归 0**——这正是第二次冲击降临的含义 |
| **旧王的苏醒** | 四位旧王**自此之后逐步复苏**，但**实力相较以往大幅下降**，需在旧域深处**缓慢恢复**；恢复期间由各自的**附属势力**在现世代为活动 |
| **新时代的开端** | 幸存者开始审视「神明」的存在，以「[炼金学](炼金武装.md)」为核心的**现代非凡体系**被建立，**工业革命**就此在现世内开展——这就是[复兴时代](时间线.md#复兴时代) |

**帷幕之内的说法**：一场**波及全球的天灾**与随之而来的**信仰崩塌**；有记载，但被解释为天灾与信仰崩塌。


## 复兴时代

**原文**

【复兴时代】

在“震怒之日”引发“第二次冲击”后的百年间，幸存者们开始审视起了“神明”的存在。

他们否定了“神明”的超然地位，将那些**以律法扭曲现实的存在**统称为“术士”，执行“帷幕计划”将一切非凡概念隔绝于人类社会之外。

随着神话时代的逐渐远去，以“炼金学”为核心的现代非凡体系确立。

在十八世纪末，以维多利亚联合王国为核心，“工业革命”就此在现世内逐渐推行，“炼金武装”的诞生使普通人也拥有了制衡术士的能力。

从此刻开始，主导现世未来的权力不再属于那些曾经自称“神明”的术士，而是属于构成这个文明的每一位个体。

### 帷幕计划

“第二次冲击”后，随着神话时代的远去与诸神的陨落，人们意识到了非凡概念广泛传播对现世的危害性，各势力开始限制任何有关非凡概念的信息流通，帷幕计划就此形成。

1. **替换归因**：把非凡事件降级为自然现象（冰盖崩解、气候异常、地质活动）。
2. **压缩时间**：把长期持续的余波（如[第三次冲击](时间线.md#千禧陆沉与第三次冲击)后“至今仍在延续”的政局动荡）拆散成互不相干的地区性新闻。
3. **切断关联**：让每一次灾难都看起来与上一次无关。

帷幕计划对现世内部术士的行动进行了严格的规范，在**现世内人口密集区域建立[源质反应堆](源质反应堆.md)，把区域内的源质浓度稳定维持在低位。**

| 对象 | 处境 |
|---|---|
| **归属官方的合法术士** | 受信任并与现世势力**深度合作**，始终具备施展律法的条件 |
| **未登记的非法术士** | 受限于现世内部的**低源质环境**，**无法获取足够施展律法的源质** |


## 第一次现世战争

**原文**

【第一次现世战争】

二十世纪初，在南极大陆的冰盖深处，一处规模空前的遗迹被联合科考团同时发现。

他们找到了至今仍在运行、通过燃烧源质以维持现世物理规则稳定的封印物“终末之环”，当他们回归后，各自所属的势力却对与那处遗迹与“终末之环”的所有权争论不休。

随着莱茵帝国的皇位继承人在巡视途中遭遇刺杀，同时发生于帷幕内外、被后世称为“第一次现世战争”的大事件就此拉开了序幕。

这场持续了四年的战争造成了数以千万计死亡，各势力受到重创，现世的深度再次处于归0的边缘。


## 第二次现世战争

**原文**

【第二次现世战争】

“第一次现世战争”结束后，现世内部进入了短暂的和平，莱茵帝国在战后的清算中损失惨重，崩溃的社会秩序加速了帝国的崩溃。

在这个动荡的时代中，名为凯撒的年轻士兵受到来自旧域深处的注视，从此投身政治，在数年时间内恢复了莱茵境内的秩序，建立了“莱茵第三帝国”。

随着“重樱帝国”与“伊塔利亚帝国”的加入，名为“帝国轴心”的组织诞生，以重樱帝国率先入侵神州北境为起点，“第二次现世战争”就此拉开序幕。

在这场再度席卷帷幕内外的战争初期，“帝国轴心”的迅猛攻势令早已在“第一次现世战争”中元气大伤的现世诸国几乎无法抵挡，现世的深度正在向归0的边缘。

通过对封印物“终末之环”的逆向工程，能够燃烧源质并将其转化为能量的“源质反应堆”被作为武器研发成功。

1945年，对“帝国轴心”的最后一战中，这件武器对一切以源质构成的存在造成了恐怖的杀伤，帝国轴心统一现世的远征失败，第二次现世战争随之结束。


## 联合国诞生

**原文**

【联合国诞生】

两次现世战争引起了无数人的深思，现世迫切需要一个能够有效预防战争、联合抵御旧域存在入侵的世界性组织。

1945年末，为了维持现世内部深度的稳定与应对来自现世之外的威胁，“联合国”在全球化思潮中诞生，次年，归属于联合国安理会、名为“先锋守望”的组织正式成立。

其在现世各区域内部署维和性质的术士部队，以此预防可能发生的非凡灾害。

随后，以终末之环产生近乎无穷无尽的能源为前提，现世各国开始了针对边境与旧域的大规模探索，科技通过对封印物的逆向工程得到了飞速的进步。

于是，自1946年起，剧烈的军备竞赛与地区性冲突代替全面热战成为了时代的主流。


## 千禧陆沉与第三次冲击

**原文**

【千禧陆沉】与第三次冲击

在1999年的世纪交替之际，伴随着“终末之环”堆芯的骤然熔毁，一场前所未有的灾难随之降临现世。

“终末之环”融毁释放的恐怖能量永久地撕裂了南极区域现世、旧域与边境之间的界限，南极大陆被彻底从现世的版图上抹去，“第三次冲击”降临。

随着大量源质的涌入，现世部分区域因物理规则崩溃导致深度骤降，无数人被转化为丧失人性的“扭曲者”，因此所引发的政局动荡至今仍在延续。

当各国官方共同签署了“千年协定”消除帷幕之内有关这次灾难一切痕迹后，现世在痛苦与迷茫中迈入了公元21世纪。

因此千禧陆沉改变了三件事：

| | 千禧陆沉之前 | 千禧陆沉之后 |
|---|---|---|
| 终末之环 | **南极深处**，持续燃烧源质 | **堆芯熔毁**，不再燃烧源质 |
| 现世内部源质浓度 | **维持较低水平**，物理规则稳定，深度持续为正 | **正在逐步提升**，物理规则失衡，深度持续降低 |
| 各方可依赖的手段 | 终末之环本身 | 原先对它**逆向工程**制造出的[**源质反应堆**](源质反应堆.md) |

各势力依靠[源质反应堆](源质反应堆.md)**延缓现世沉入旧域的进程**——但也仅止于此；它**以[辉石](源质.md)为燃料**，而现世的辉石储量有限且不可再生。

详见 [封印物 · 终末之环](封印物.md)。

### 它留下的东西

| 遗产 | 说明 |
|---|---|
| **[黄金树](黄金树.md)** | 事件后诞生的自然奇观——终末之环融毁释放的恐怖能量**永久撕裂了南极区域现世、旧域与边境之间的界限**，南极大陆被从现世版图上抹去；区域内源质浓度升高时，一道**贯穿三层世界**的**金色裂痕**出现在南方天空 |
| **[源质反应堆](源质反应堆.md)** | 终末之环消失后，规模不同的反应堆们成为**维持现世稳定的临时措施** |
| **[帷幕计划](时间线.md#帷幕计划)** | 由「千年协定」启动，**替换归因**地把灾难降级为自然现象 |
| **动荡未平** | 1999 年的政局动荡**至今仍在延续** |

**帷幕之内的说法**：「千禧陆沉」——**南极冰盖崩解**引发的**全球性自然灾害与气候动荡**；属**被主动掩盖的当代事件**，[帷幕计划](时间线.md#帷幕计划) 的直接对象。


## 联合国解体

**原文**

【联合国解体】

在“千年协定”签署后，“帷幕计划”随之开展，一切有关于世纪之交那场灾难的信息成为了普通人眼中的传说。

但在帷幕之外，这场灾难的余波仍在延续。

在2001年，震惊整个现世的“911”事件发生。

本次事件以恐怖袭击的方式被帷幕之内的存在知晓，它的真实发起者并非官方叙事里的恐怖组织，是[旧王](旧王.md)的衍生势力「**世外天国**」为离间现世内部各势力而发动的隐秘行动

此后十年间，在各国矛盾逐步激化、恐怖主义盛行的情况下，地区性冲突频发，而“联合国”却无力继续支持在现世范围内维系稳定的行动。

2012年，“联合国”正式宣告解体，“先锋守望”也随联合国的解体而自动解散。

理想破灭后，心灰意冷的干员们开始各自谋求生路，部分干员选择与当地官方势力合作，恪守维持现世稳定的职责。

而另一部分干员则拒绝与官方势力合作，他们对一切秩序与法律视而不见，就此成为了现世内部的不稳定因素之一。

**解体后的现世格局**

> - 由**现世内各国官方势力 + 选择与各国官方势力合作的合法术士**构成的武装力量，维持「一切有关于非凡的概念被严格封锁」这一局面；

> - 与之对立的是**拒绝与官方合作的非法术士**，以及**现世暗面中的旧王衍生势力**；
> - 现世格局**没有中心结构**——各国各自为政，只在必要时临时协作，情报并不共享；
> - 非法术士**没有统一目标**，行动目的不一，却因行为模式高度相似而被归为一类。

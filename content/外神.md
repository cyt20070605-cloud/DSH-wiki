## 外神

**原文**

外神

位于群星深处的高位存在，诞生于万物创生之初，世界的死与生对于祂们而言近乎没有任何影响。

作为超越认知之外的存在，外神们仅遵循着各自的本能而行动，但祂们恐怖的力量却会在潜移默化间影响世界的进程。

上位外神：

【无上意志】

【轮回终末】

次位外神：

【绛天之龙】

【铸形之炎】

【伏行之恶】

## 代行者体系

**每一位外神都拥有自己的代行者。**

| 外神 | 等级 | 代行者 |
|---|---|---|
| **无上意志** | 上位 | [旧王](旧王.md) |
| **轮回终末** | 上位 | **无名之王** |
| **绛天之龙** | 次位 | [古龙](天灾.md) |
| **铸形之炎** | 次位 | [灰潮](天灾.md) |
| **伏行之恶** | 次位 | [神孽](天灾.md) |

外神本身仅遵循本能、不直接干预世界；**代行者就是祂们的意志落进世界的方式**。因此：

- [天灾](天灾.md) 它们是三位次位外神的**代行者**——且作为**群体性存在**，其实力因个体而异，没有统一位格。
- [旧王](旧王.md) 祂们是**无上意志**的**代行者**。

- **轮回终末**同样拥有**代行者**，祂引发了**第一次冲击**，令高天之上的烈火降临于世、将第五纪元的可能性自**原初律法**中解放，就此阻止**无上意志**支配万物的进程，成为第五纪元的**无名之王**。

### 上位外神

上位外神的两者，在世界该被导向何处这一点上**完全相反**：

| | **无上意志** | **轮回终末** |
|---|---|---|
| 本能 |**以自身意志支配万物的绝对秩序**  | **不再受任何存在制约的绝对混沌** |
| 结果 | **一切可能性都将不复存在** | **更多的可能性将得到解放** |
| 二者的关系 | —— **在本能层面上存在绝对的对立** —— | |

> 也就是说：**无上意志要的是"只剩一种可能"，轮回终末要的是"没有任何定则"。** 但取向的对立**并不等于**两者的权能都只有破坏性——见下。

这层对立给[律法归一](律法.md)的终局补上了另一面：律法趋向归一并不是世界的唯一意志——**还有一位上位外神，其本能就是不让它实现**。

### 往复轮回的成因

两者的权能**对世界本身都有一定正面意义**——但方向相反，且**发展向极端时都会毁灭世界**：

| | **轮回终末** | **无上意志** |
|---|---|---|
| 引导方向 | 自**由律法规划的绝对秩序** → 引向**具有无限可能性的新生** | 自**不存在秩序的绝对混沌** → 引向**失去一切可能性的终结** |
| 正面意义 | **解放**——为世界带去更多的可能性 | **秩序**——使世界不至在无序中消亡 |
| 走向极端的后果 | **绝对混沌**→ 毁灭世界 | **绝对秩序**→ 毁灭世界 |

> **故两者相互制衡，创造了世界往复轮回的奇景**——「世界自烧却混沌的烈火中诞生，又将在终结万物的[旧域](四层世界.md#旧域)中死去」这一往复，正是这一制衡的体现。详见 [纪元](世界往复.md)。

### 外神的特征

- **位置**：位于 [群星](四层世界.md#群星) 深处。
- **起源**：诞生于万物创生之初。
- **行为方式**：作为超越认知之外的存在，仅遵循各自的本能而行动；但恐怖的力量会在潜移默化间影响世界的进程。
- **位格**：**[原型界](力量体系.md)**（超越 9 环）——上位外神与次位外神同在原型界。
  > 注意：[旧王](旧王.md) 不在这一界——祂们**位格在创造界**，只是**实力比肩次位外神**（见 [能力体系](力量体系.md)）。

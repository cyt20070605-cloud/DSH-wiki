> **补充设定**：四层世界之间的通行方式与代价；与原文冲突处以原文为准。

## 基本前提（来自原文）

- [现世](world.md#现世)：有序，一切有关于非凡的概念被严格封锁。
- [边境](world.md#边境)：无序，**独立**于现世与旧域之外，不被现世接纳的存在常年汇聚于此。
- [旧域](world.md#旧域)：混沌，一切死去世界的最终归宿，混乱无序是永恒铁律。
- [群星](world.md#群星)：归属于外神，时间与空间概念不复存在。

推论：既然边境是"缓冲区域"且**独立于**两侧，那么现世 ↔ 边境 ↔ 旧域之间必然存在可通行的接缝；否则"缓冲"与"汇聚"无从谈起。而现世既然要"严格封锁非凡概念"，这些接缝就必然是**被管控的对象**。

## 通行规则的两条硬边界

### 群星只能被"抵达"

> 群星**不可"通行"，只能被"抵达"**——它不在空间之中，因此无法被进入或离开。

这意味着四层世界里只有**三层**存在真正意义上的"通路"：现世 ↔ 边境 ↔ 旧域。群星是**结果**而非**目的地**——它与外神、"时间与空间概念不复存在"的属性一致，只能以某种非通行的方式触及（具体方式尚未展开）。

### 通路能封，但封不永久

> 通路**能封但代价高、会重开**——封闭一条通路需要持续供能与人力，且终会被重新撕开。

**封闭的手段是[源质反应堆](artifact-relic.md)**：在接缝附近**就地燃烧游离态源质** → 该区域**源质浓度下降** → **区域修正值回升过 0** → 天然裂隙**失去形成条件而闭合**。这与天然裂隙"形成于修正值长期低于 0 的地带"正好是同一原理的**反向运用**。

```
封锁一条通路
   ├─ 需要：源质反应堆（就地燃烧游离态源质，把修正值抬回 0 以上）+ 常驻人力（干员/部队）
   └─ 效果：暂时有效
        └─ 一旦供能中断或人力撤离 → 修正值重新跌破 0 → 重新撕开
             └─ 而维稳网是无中心结构 → 总有人先撤
```

> **封路与「延缓现世沉入旧域」在抢同一批燃料。** [源质反应堆](artifact-relic.md) 本就是各势力对[终末之环](artifact-relic.md) 逆向工程、用于**延缓现世沉没**的造物——把它调去封路，意味着**维稳与续命是同一个预算**。

因此通路的封锁**不是没人管，而是管不过来**。

## 通路类型

| 通路 | 形态 | 稳定性 | 主要使用者 |
|---|---|---|---|
| 天然裂隙 | 修正值长期低于 0 的地带自然形成的接缝 | 低，位置漂移 | [奇幻种](race-fantasy.md)、走私者、失控的畸变体 |
| 人工门径 | 以[炼金学](alchemy.md)与辉石能量维持的定向通路 | 高，但昂贵且需持续供能 | 各国官方、前[先锋守望](timeline.md)干员、正规术士部队 |

## 通行代价

1. **修正值冲击**：跨越接缝时，个体承受的源质浓度骤变。按[能力体系](power-system.md)的阶段，普通人穿越天然裂隙的畸变风险极高，术士则视环阶而定——**这正是"抗性"最实际的意义**。
2. **单向性倾向**：向旧域方向通行易、返回难（旧域混乱无序、缺乏稳定坐标）。这也是"任何时代的遗迹皆有可能在旧域内出现"却极少被完整带出的原因。
3. **人格磨损**：长期往返者会出现感知偏移，与高环术士的人格崩溃同源但更慢。
4. **现世侧代价**：私自穿行会把通行本身暴露给更多人知晓，因此是各国官方与维稳势力的重点打击对象。

## 谁能往返

| 主体 | 可通行范围 | 说明 |
|---|---|---|
| 普通人 | 理论上不可 | 天然裂隙穿越基本等于畸变 |
| 低–中环术士 | 现世 ↔ 边境 | 需依托人工门径 |
| 高环术士 | 可及旧域边缘 | 代价是自身人格的进一步崩解 |
| [奇幻种](race-fantasy.md) | 世代居于边境 | 血脉中融入律法者，对边境环境有天然适应性 |
| [龙裔](race-dragonkin.md) | 无固定聚居地 | 数量极稀少，多数行踪不明 |
| 旧王衍生势力 | 见下方"尚未展开" | 各家掌握的通路手段均未展开 |

## 治理现状

按「各国官方 + 前先锋守望合作派干员维稳，对抗叛离派与渗透者」的格局：

- 各国官方掌握**人工门径**的审批与供能。
- 前先锋守望合作派干员负责**巡查天然裂隙**。
- 叛离派干员与被旧域注视者则**利用天然裂隙走私**人员、[遗物](artifact-relic.md)与情报。

## 尚未展开

- 四大旧王衍生势力各自的通行手段（尤其[无邦者](old-kings.md)是否掌握独立通路）。
- 群星以何种"非通行"方式被触及——它只能被"抵达"，而"抵达"的具体形式尚未确立。
- **源质反应堆的数量与部署成本**：封路靠就地燃烧源质把修正值抬回 0 以上，但现世究竟有多少台反应堆、由谁提供与审批，尚未确立（并与「[遗物](artifact-relic.md) 由哪一方逆向工程」同题）。
- 永久关闭通路的手段：不存在，或至少从未被发现。

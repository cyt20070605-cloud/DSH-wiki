## 一句话概括

**为了掐灭旧域的威胁，前文明按下了那个尚未准备好的开关。**

## 原文摘录

摘自 [时间线](时间线.md) 的「破碎战争与第一次冲击」节：

> 作为前文明“新世工程”的最终产物，终末之环拥有着燃尽世间源质的恐怖威能，它的存在令旧域中一切以源质构成的存在都面临前所未有的威胁。
>
> 于是，“破碎战争”就此爆发。

> 在“破碎战争”末期，面对早已无力回天的现实，尚未完成的“终末之环”被迫提前点火，不受控制的链式反应撕裂了维度间的界限，引动高天之上的烈火降临于世。

## 关键事实

| 项 | 内容 |
|---|---|
| **时间** | 旧时代末期（[黄金年代](时间线.md) 之后），**无确切年份** |
| **战争的缘由** | [终末之环](终末之环.md) 作为前文明「**新世工程**」的**最终产物**，拥有**燃尽世间[源质](源质.md)**的恐怖威能；它的存在令[旧域](四层世界.md#旧域)中一切**以源质构成的存在**都面临前所未有的威胁 |
| **爆发** | 「破碎战争」由此爆发 |
| **末期的转折** | 面对**早已无力回天的现实**，**尚未完成**的终末之环**被迫提前点火** |
| **启动机制** | **不受控制的链式反应撕裂了维度间的界限**，引动**高天之上的烈火**降临于世 |
| **结果** | 「第一次冲击」随之降临 |

> **「高天之上的烈火」是什么**：即**创立世界**的上位外神「[轮回终末](外神.md)」的烈火——与「烧却混沌的烈火」**同一物**；「[新世](新世工程.md)」工程篡夺的正是祂的权能。

## 第一次冲击

| 项 | 内容 |
|---|---|
| **代价** | **前文明的毁灭** |
| **换来了什么** | 「[原初律法](律法.md)」**分崩离析**；**一切可能性被从[无上意志](外神.md)手中解放** |
| **结果** | 「[新世](新世工程.md)」工程取得**惨烈的成功**——「新世」的**存在被确定**，只是**如今尚未降临** |
| **世界的形状** | **动荡的第五纪元仍在延续**；[现世](四层世界.md#现世)、[边境](四层世界.md#边境)与[旧域](四层世界.md#旧域)的划分随之出现 |
| **时代主角** | **执掌律法的存在**逐渐成为这个时代的主角 |
| **伏笔** | 为争夺**那唯一的王位**，新一轮的纷争正在**历史的暗面**中涌动 |

## 它留下的东西

这场战争是此后一切非凡格局的起点：

| 遗产 | 说明 |
|---|---|
| **[原初律法](律法.md)的碎片** | 战后分崩离析、分散至各地——**最初的[术士](术士.md)与[封印物](封印物.md)也随之诞生** |
| **[奇幻种](奇幻种.md)** | 战后祖先因**接触破碎的原初律法**而产生突变，各不相同的律法随**血脉**流传至今 |
| **[人类](人类.md)** | 即**破碎战争幸存者**——前文明的后裔 |
| **[神明](神明.md)** | 破碎战争**之后**执掌律法的非凡存在，为混沌的世界带来最初的秩序 |
| **[旧王](旧王.md)的沉寂** | [外神](外神.md)、[天灾](天灾.md)与旧王们因破碎战争的**余波而沉寂**，神明才得以成为世间的顶点 |

> 战后接下来的，是[神话时代](时间线.md)——过往历史被旧王扭曲，为数不多的幸存者为争夺律法而厮杀。

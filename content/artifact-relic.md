**原文**

【遗物】

“遗物”通常用来代指被发现于“旧域”与“边境”内、具有各式非凡能力的神秘物品。

## 要点

- **指代对象**：被发现于 [旧域](world.md#旧域) 与 [边境](world.md#边境) 内、具有各式非凡能力的神秘物品。
- **本质**：**世界毁灭后的文明残余**——不是"被封存之物"，而是"幸存的残余"。
- **与律法的关系**：遗物被摧毁时，赋予其非凡能力的 [律法](law.md) 会脱离主体，直到新的遗物形成或被其他 [术士](sorcerer.md) 融合。
- **稀缺性**：正因遗物稀缺，[炼金武装](alchemy-arms.md) 的概念才作为其替代品而诞生。
- **来源的宽度**：[旧域](world.md#旧域)是一切死去世界的最终归宿，**每一场毁灭都往里面留下过东西**。

## 什么是遗物

关键在"残余"二字，它决定三条不可动摇的性质：

1. **它不是为被使用而造的。** 遗物是某个文明的**遗存**，非凡能力往往是它作为物的"副作用"，而不是设计目的——这与[炼金武装](alchemy-arms.md)（**为使用而造**）正好相反。
2. **它没有原主。** 制造它的文明已经毁灭，因此不存在"归还"，也不存在"授权"。
3. **它必然残缺。** 从一场毁灭里留下来的东西，本身就是碎片。

## 遗物的来源

遗物没有"分类"，只有**来源的多少**。[旧域](world.md#旧域)是一切死去世界的最终归宿，**每一场毁灭都往里面留下过东西**：

```
世界毁灭 ──► 文明残余 ──► 遗物
                          │  各时代、各世界，混在旧域与边境
                          └─ 其中一部分来自前文明
```

**前文明的产物就是遗物**，不是另一种东西。它与别处遗物的差别只有两点：**来源明确**（知道它属于哪一场毁灭），以及**本体集中在[旧域](world.md#旧域)深层**。

| | 一般的遗物 | 来自前文明的遗物 |
|---|---|---|
| 来源 | 各时代、各世界的毁灭，往往无从追溯 | **明确**——前文明这一场毁灭 |
| 本体位置 | 散落于旧域与边境 | **集中在旧域深层** |
| 被摧毁时 | [律法](law.md)脱离主体，等待新的遗物形成或被融合 | 同样如此 |

> 来自前文明的遗物不构成遗物的第二支，只是**来源被认出来的那一部分**——**终末之环**也只是其中之一。

现世的非凡物品经济建立在整个遗物层之上：走私、拍卖、逆向工程、[炼金武装](alchemy-arms.md) 的替代关系，全部指向**遗物**。

> **遗物可以被仿造，但仿造品不是遗物。** 现世最重要的仿造成果是**源质反应堆**——在终末之环基础上逆向工程而来，用于燃烧源质、**延缓现世沉入旧域的进程**。它是造物，不是残余：**为使用而造、有明确的原主、可以复制**——正好是遗物的三条性质的镜像反面。

> **前文明不存在组织。** 破碎战争之后，任何源自前文明的组织都不复存在；前文明的遗产只有两种形态：**遗物**，以及一位**身份尚不得知**的代行者（见[外神](outer-gods.md)）。

## 终末之环

**「终末之环」也是一件遗物。** 遗物中最重的一件。它**规模空前、威能灭世**——但它仍然是一件遗物，因为它同样出自一个毁灭的世界，同样没有原主、无法复制、终究残缺。

| 项 | 内容 |
|---|---|
| **归类** | **遗物** —— 前文明留下的遗物，世界毁灭后的文明残余 |
| **身份** | 前文明在**科技领域的至高之作**，「[新世](timeline.md)」工程的核心 |
| **能力** | 通过**燃烧[源质](essence.md)**产生几乎无穷无尽的能源 |
| **威能** | 拥有**燃尽一切源质**的恐怖威能——一旦完全启动，旧域中一切以源质构成的存在都将面临前所未有的威胁 |
| **所在地** | **南极大陆冰盖深处**；二十世纪初被联合科考队**重新发现**，此后成为现世的能源基石 |

### 它一直在压着现世的源质浓度

终末之环的燃烧并非只是发电。在**千禧陆沉之前**，它持续燃烧源质、把[现世](world.md#现世)内部的源质浓度**压在较低水平**——现世之所以还能"有序"，很大程度上是这件遗物在替它维持。

> 也就是说：**现世最重要的一件遗物，同时是现世得以存在的条件之一。**

### 千禧陆沉之后：沉入旧域，倒计时开始

| 阶段 | 终末之环的状态 | 现世的处境 |
|---|---|---|
| 千禧陆沉之前 | 位于南极大陆冰盖深处，**持续燃烧源质** | 内部源质浓度**被压在较低水平**，稳定 |
| [千禧陆沉](timeline.md) | **堆芯熔毁** → 四分之三南极冰盖被炸毁 → 狂暴源质涌入现世 | 「[第三次冲击](timeline.md)」降临，部分区域向[边境](world.md#边境)转化 |
| 千禧陆沉之后 | **沉入[旧域](world.md#旧域)深处**，不再为现世工作 | 内部源质浓度**正在逐步提升**，[修正值](correction.md)随之持续走低 |

三条连锁后果：

1. **现世失去的不是能源，是"压舱物"。** 没有了它持续燃烧源质，浓度只能单向累积。
2. **各势力手里只剩下仿制品。** 他们依靠的，是原先**对终末之环做逆向工程**制造出的**源质反应堆**——它们能延缓现世沉入[旧域](world.md#旧域)的进程，但**无法逆转它**。
3. **现世的毁灭进入了不可逆转的倒计时。** 这不是预言，而是已经开始的物理过程：浓度每上升一分，修正值就低一分，向边境与旧域转化的区域就多一片。

> 现世"正在逐渐死去"这句原文，在这里有了确切的成因与刻度。

### 为什么它是遗物，而不是别的什么

即使它曾经几乎灭世、曾经托着整个现世，也脱离不了遗物的范畴：

- **它没有原主**——造它的前文明已经毁灭，因此它的归属从诞生之初就是空的。
- **它不可复制**——现世对它的全部掌握来自**逆向工程**，而非理解其原理；后世的终极武器与源质反应堆都只是它基础上的仿制。
- **它必然残缺**——「新世」工程未能完成，它是被**被迫启动**的半成品，这一点从未被修复；工程虽**成功篡夺权能**、使「永诀律法之新世」的**存在被确定**，但那世界**至今尚未降临**。
- **它没有意志**——它是一件物，不是一位存在；驱动它的是源质与工程，不是意图。

> 换言之：**它的分量来自它能做什么，而不是它是什么。** 无论威能多大，它都只是一件文明残余。

## 它在历史中的位置

| 阶段 | 说明 |
|---|---|
| [旧时代](timeline.md) | 前文明以它为至高造物核心，展开「新世」工程 |
| [破碎战争](timeline.md) | **尚未完成**时被迫启动，终结了战争 |
| 第一次冲击 | 以前文明的毁灭为代价，[原初律法](law.md)分崩离析；它沉眠于南极大陆冰盖深处 |
| 数千年的沉眠 | 历经[混沌时代](timeline.md) → [震怒之日](timeline.md) → [复兴时代](timeline.md) |
| 二十世纪初 | 被联合科考队**重新发现**（非首次发现），发现它**至今仍在运行**；其所有权之争引爆[第一次世界大战](timeline.md) |
| [第二次世界大战](timeline.md) | 各国在它基础上研发出能够燃烧源质的**终极武器** |
| [联合国诞生](timeline.md) | 以它近乎无穷无尽的能源为前提，针对各遗迹的大规模开发与遗物逆向工程随之展开 |
| [千禧陆沉](timeline.md) | **堆芯熔毁** → 四分之三南极冰盖被炸毁 → 狂暴源质涌入现世 → 「[第三次冲击](timeline.md)」 |
| 千禧陆沉之后 | **沉入[旧域](world.md#旧域)深处**；现世转入不可逆转的倒计时 |

它与上位外神「[轮回终末](outer-gods.md)」是**同源的"燃尽"意志**——同源是经由**代行者**这一层实现的：轮回终末同样拥有自己的代行者，而**其身份尚不得而知**。详见 [外神 · 代行者体系](outer-gods.md)。

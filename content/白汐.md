## 0. 定位

白泽事务所所长，纯血[奇幻种](奇幻种.md)·白泽，当代左海现世安全局局长之女——她的律法能让身边的一切信息无所遁形，但[纪原](纪原.md)却是例外。。

## 3. 律法

| 项 | 内容 |
|---|---|
| **律法名称** | 通透视界 |
| **权能** | 全天候接收周围一切信息，过载级的输入量 |
| **边界** | 读不到[纪原](纪原.md)。他对非凡信息的感知近乎空白，在她眼里是一块信息真空 |
| **触发条件 / 代价** | 大量信息冲击将会使她的意识过载，为了抵御这份“天赋”对自身的影响，她只能习惯性地将自己封闭，外人眼中的「高岭之花」是律法的副作用，而非她的真正性格 |
| **是否已知其来源** | 原初律法碎片（血脉传承） |

## 4. 身份（帷幕内外）

| 项 | 内容 |
|---|---|
| **合法 / 非法** | 合法术士——**白泽事务所**，依照《新神州术士管理条例》注册 |
| **帷幕之外** | 白泽事务所所长；左海市现世安全局局长之女 |
| **帷幕之内** | 一间接受各方委托的私人侦探事务所主理人 |
| **非凡信息暴露程度** | 严格保密 |

父亲白君浪因在2012年“左海港大爆炸”事件中，继任左海现世安全局局长。他不许她以官方身份查 2012 年的事，她便自己注册了一间事务所——明面上给官方接外包刷声望，暗地里查自己的。

## 9. 成长路线

把纪原当成需要看管的遗物 → 被迫承认他的判断 → 发现父亲／局内与 2012 年的真相有关，世界观塌一次 → 不再用「继承者的守护者」定义自己。

动机三条：查清 2012 的真相；把纪原练成能活下来的人——律法不能第二次遗失，名号不能再蒙羞；向父亲证明不靠他也能做成。

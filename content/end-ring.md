### 它维持着现世的稳定

在**千禧陆沉之前**，它持续燃烧源质、把[现世](world.md#现世)内部的源质浓度**压在较低水平**——现世之所以还能"有序"，很大程度上是这件封印物在替它维持。

> 也就是说：**现世最重要的一件封印物，同时是现世得以存在的条件之一。**

### 千禧陆沉之后：沉入旧域，倒计时开始

| 阶段 | 终末之环的状态 | 现世的处境 |
|---|---|---|
| 千禧陆沉之前 | 位于南极大陆冰盖深处，**持续燃烧源质** | 内部源质浓度**被压在较低水平**，稳定 |
| [千禧陆沉](timeline.md) | **堆芯熔毁** → 南极大陆被彻底炸毁 → 狂暴源质涌入现世 | 「[第三次冲击](timeline.md)」降临，部分区域向[边境](world.md#边境)转化 |
| 千禧陆沉之后 | **沉入[旧域](world.md#旧域)深处**，不再为现世工作 | 内部源质浓度**正在逐步提升**，[修正值](correction.md)随之持续走低 |

三条连锁后果：

1. **各势力手里只剩下仿制品。** 他们依靠的，是原先**对终末之环做逆向工程**制造出的[**源质反应堆**](reactor.md)——它们能延缓现世沉入[旧域](world.md#旧域)的进程，但**无法逆转它**。
2. **现世的毁灭进入了不可逆转的倒计时。** 这不是预言，而是已经开始的物理过程：浓度每上升一分，修正值就低一分，向边境与旧域转化的区域就多一片。

## 它在历史中的位置

| 阶段 | 说明 |
|---|---|
| [旧时代](timeline.md) | 前文明以它为至高造物核心，展开「新世」工程 |
| [破碎战争](timeline.md) | **尚未完成**时被迫启动，终结了战争 |
| 第一次冲击 | 以前文明的毁灭为代价，[原初律法](law.md)分崩离析；它沉眠于南极大陆冰盖深处 |
| 数千年的沉眠 | 历经[混沌时代](timeline.md) → [震怒之日](timeline.md) → [复兴时代](timeline.md) |
| 二十世纪初 | 被联合科考队**重新发现**（非首次发现），发现它**至今仍在运行**；其所有权之争引爆[第一次世界大战](timeline.md) |
| [第二次世界大战](timeline.md) | 各国以它为依托进行**逆向工程**，制造出的[**源质反应堆**](reactor.md)被作为武器投入使用——**结束二战的不是它本身，而是这件仿制物** |
| [联合国诞生](timeline.md) | 以它近乎无穷无尽的能源为前提，针对各遗迹的大规模开发与封印物逆向工程随之展开 |
| [千禧陆沉](timeline.md) | **堆芯熔毁** → 南极大陆被彻底炸毁 → 狂暴源质涌入现世 → 「[第三次冲击](timeline.md)」 |
| 千禧陆沉之后 | **沉入[旧域](world.md#旧域)深处**；现世转入不可逆转的倒计时 |

它与上位外神「[轮回终末](outer-gods.md)」是**同源的"燃尽"意志**——同源是经由**代行者**这一层实现的：轮回终末同样拥有自己的代行者，而**其身份尚不得而知**。详见 [外神 · 代行者体系](outer-gods.md)。

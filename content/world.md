## 群星

> 定位：顶层 · 未知区域 ｜ 归属：[外神](outer-gods.md)

**原文**

群星

位于顶层的未知区域，联通了现世、边境与旧域。

群星是归属于外神的神秘领域，链接着过去、现在与未来，时间与空间的概念在此不复存在。

**要点**

- 顶层未知区域，同时联通现世、边境与旧域。
- 归属外神的神秘领域。
- 链接过去、现在与未来；时间与空间的概念在此不复存在。

## 现世

> 定位：上层 · 有序区域 ｜ 状态：正在逐渐死去

**原文**

现世

位于上层的有序区域，是正在逐渐死去的世界。

一切有关于非凡的概念在这里被严格封锁，各势力以此维系着现世的稳定与文明的未来。

**要点**

- 上层有序区域，是正在逐渐死去的世界。
- 一切有关于非凡的概念在此被严格封锁，各势力以此维系现世的稳定与文明的未来。
- [旧王](old-kings.md) 的目标之一即是将现世与边境彻底沉入旧域。

## 边境

> 定位：中层 · 无序区域 ｜ 角色：缓冲区域

**原文**

边境

位于中层的无序区域，游离于现世与旧域之间的世界。

作为现世与旧域的缓冲区域，边境独立于现世与旧域之外，那些不被现世接纳的存在常年汇聚于此。

**要点**

- 中层无序区域，游离于现世与旧域之间。
- 作为缓冲区域，**独立**于现世与旧域之外。
- 不被现世接纳的存在常年汇聚于此（如 [奇幻种](race-fantasy.md)）。

## 旧域

> 定位：底层 · 混沌区域 ｜ 角色：一切死去世界的最终归宿

**原文**

旧域

位于底层的混沌区域，是一切死去世界的最终归宿。

混乱无序是这里永恒不变的铁律，任何时代的遗迹皆有可能在旧域内出现，其中甚至可能存放着上个纪元的遗物（见 [纪元](world-cycle.md)）。

**要点**

- 底层混沌区域，是一切死去世界的最终归宿。
- 混乱无序是这里永恒不变的铁律。
- 任何时代的遗迹皆有可能在旧域内出现，甚至可能存放上个纪元的遗物。
- 发现产出：[遗物](artifact-relic.md) 通常被发现于旧域与边境内。

## 层级关系

| 层级 | 区域 | 有序度 | 关键特征 | 相关条目 |
|---|---|---|---|---|
| 顶层 | 群星 | 未知 | 归属于外神；时间与空间概念不复存在 | [外神](outer-gods.md) |
| 上层 | 现世 | 有序 | 正在逐渐死去；非凡概念被严格封锁 | [人类](race-human.md) |
| 中层 | 边境 | 无序 | 缓冲区域；不被现世接纳者汇聚 | [奇幻种](race-fantasy.md) |
| 底层 | 旧域 | 混沌 | 一切死去世界的归宿；上个纪元遗物 | [旧王](old-kings.md) |

## 区域转化的判据

[修正值](correction.md) 高于 0 则稳定、低于 0 则无序，并直接决定现世、边境、旧域之间的相互转化。原文中的实例：

- 「[震怒之日](timeline.md)」：现世的修正值正式跨越 0 的界限，第二次冲击降临。
- 「[千禧陆沉](timeline.md)」：骤降的修正值使现世部分区域向边境转化。
- [联合国](timeline.md) 成立目的之一：维持现境内部修正值的稳定。

# 四层通行

> **补充设定**：四层世界之间的通行方式与代价。与原文冲突处以原文为准。

## 三层可通行，群星只能被"抵达"

四层结构确立了四个区域，但**只有三层之间存在真正意义上的"通路"**：现世 ↔ 边境 ↔ 旧域。

> 群星**不可"通行"，只能被"抵达"**——它不在空间之中，因此无法被进入或离开。

这不是附会，而是上文的直接推论：边境既然是"缓冲区域"且**独立**于两侧，那么现世 ↔ 边境 ↔ 旧域之间必然存在可通行的接缝；否则"缓冲"与"汇聚"无从谈起。而现世既然要"严格封锁非凡概念"，这些接缝就必然是**被管控的对象**。

群星则是唯一的例外——它与外神、"时间与空间概念不复存在"的属性一致，是**结果**而非**目的地**，只能以某种非通行的方式触及（具体方式尚未展开）。

## 阻止区域间通行的方式

> 通路**能封但代价高、会重开**——封闭一条通路需要持续供能与人力，且终会被重新撕开。

**封闭的手段是[源质反应堆](artifact-relic.md)**：在接缝附近**就地燃烧游离态源质** → 该区域**源质浓度下降** → **区域修正值回升过 0** → 天然裂隙**失去形成条件而闭合**。这与天然裂隙"形成于修正值长期低于 0 的地带"正好是同一原理的**反向运用**。

```
封锁一条通路
   ├─ 需要：源质反应堆（就地燃烧游离态源质，把修正值抬回 0 以上）+ 常驻人力（干员/部队）
   └─ 效果：暂时有效
        └─ 一旦供能中断或人力撤离 → 修正值重新跌破 0 → 重新撕开
             └─ 而维稳网是无中心结构 → 总有人先撤
```

> **封路与「延缓现世沉入旧域」在抢同一批燃料。** [源质反应堆](artifact-relic.md) 本就是各势力对[终末之环](artifact-relic.md) 逆向工程、用于**延缓现世沉没**的造物——把它调去封路，意味着**维稳与续命是同一个预算**。

因此通路的封锁**不是没人管，而是管不过来**。

## 通路类型

| 通路 | 形态 | 稳定性 | 主要使用者 |
|---|---|---|---|
| 天然裂隙 | 修正值长期低于 0 的地带自然形成的接缝 | 低，位置漂移 | [奇幻种](race-fantasy.md)、走私者、失控的畸变体 |
| 人工门径 | 以[炼金学](alchemy.md)与辉石能量维持的定向通路 | 高，但昂贵且需持续供能 | 各国官方、前[先锋守望](timeline.md)干员、正规术士部队 |

## 通行代价

1. **修正值冲击**：跨越接缝时，个体承受的源质浓度骤变。按[能力体系](power-system.md)的阶段，普通人穿越天然裂隙的畸变风险极高，术士则视环阶而定——**这正是"抗性"最实际的意义**。
2. **单向性倾向**：向旧域方向通行易、返回难（旧域混乱无序、缺乏稳定坐标）。这也是"任何时代的遗迹皆有可能在旧域内出现"却极少被完整带出的原因。
3. **人格磨损**：长期往返者会出现感知偏移，与高环术士的人格崩溃同源但更慢。
4. **现世侧代价**：私自穿行会把通行本身暴露给更多人知晓，因此是各国官方与维稳势力的重点打击对象。

## 谁能往返

| 主体 | 可通行范围 | 说明 |
|---|---|---|
| 普通人 | 理论上不可 | 天然裂隙穿越基本等于畸变 |
| 低–中环术士 | 现世 ↔ 边境 | 需依托人工门径 |
| 高环术士 | 可及旧域边缘 | 代价是自身人格的进一步崩解 |
| [奇幻种](race-fantasy.md) | 世代居于边境 | 血脉中融入律法者，对边境环境有天然适应性 |
| [龙裔](race-dragonkin.md) | 无固定聚居地 | 数量极稀少，多数行踪不明 |
| [旧王衍生势力](old-kings.md) | 旧域 → **边境** → 现世 | **必须经边境中转**；依赖天然或人工通路，**无固定途径** |

## 治理现状

按「各国官方 + 前先锋守望合作派干员维稳，对抗叛离派与渗透者」的格局：

- 各国官方掌握**人工门径**的审批与供能。
- 前先锋守望合作派干员负责**巡查天然裂隙**。
- 叛离派干员与被旧域注视者则**利用天然裂隙走私**人员、[遗物](artifact-relic.md)与情报。

## 旧王衍生势力如何进入现世

> **必须经过边境的中转**，依赖**天然或人工通路**实现，**无固定途径**。

- **没有专属通路**：四家都不能自建门径，只能借用现成的**天然裂隙**或**人工门径**。
- **必须走边境**：现世与旧域之间隔着边境，所以它们的来路必然穿过这条缓冲带 —— 而边境正是维稳网巡查的对象（[合作派干员负责巡查天然裂隙](timeline.md)）。
- **无固定途径**：没有一条能长期复用、固定下来的路线。

> 由此，它们的存在方式只能是**渗透与经营**，而不是投送 —— 这与「[以经营为手段](old-kings.md)」的定位一致。

## 「永久关闭」为什么办不到

> **不存在永久关闭通路的手段。** 这不是秘密，而是**物理上办不到**。

接缝**不是可以堵死的洞**，而是**区域修正值长期低于 0 时自然出现的现象**（见上方「通路类型」）。所以要"永久关闭"它，等于要把该区域的修正值**永久**抬到 0 以上——而修正值取决于**游离态[源质](essence.md) 的浓度**，源质**不可开采、不可储运**，且广泛分布于世界每一个角落（见 [修正值](correction.md)）。

于是只剩一条路：**持续燃烧**。而**一旦停止燃烧，浓度立刻回升，接缝重新撕开**。

> **唯一的成功案例是一件已经失去的遗物**：千禧陆沉之前，现世的稳定正是靠 [终末之环](artifact-relic.md) **唯一一次**做到了这件事 —— 而它已经沉入旧域深处。

## 尚未展开

- 群星以何种"非通行"方式被触及——它只能被"抵达"，而"抵达"的具体形式尚未确立。
- **源质反应堆的数量与部署成本**：封路靠就地燃烧源质把修正值抬回 0 以上，但现世究竟有多少台反应堆、由谁提供与审批，尚未确立（并与「[遗物](artifact-relic.md) 由哪一方逆向工程」同题）。

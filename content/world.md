## 群星

> 定位：顶层 · 未知区域 ｜ 归属：[外神](outer-gods.md)

**原文**

群星

位于顶层的未知区域，是世间一切源质的根源。

群星是归属于外神的神秘领域，链接着过去、现在与未来，时间与空间的概念在此不复存在。

## 现世

> 定位：上层 · 有序区域 ｜ 正在逐渐死去的世界

**原文**

现世

位于上层的有序区域，是正在逐渐死去的世界。

一切有关于非凡的概念在这此受到了严格封锁，各势力以此维系着现世的稳定与文明的未来。

## 边境

> 定位：中层 · 无序区域 ｜ 现世与旧域的缓冲区

**原文**

边境

位于中层的无序区域，游离于现世与旧域之间的世界。

作为现世与旧域的缓冲区域，边境独立于现世与旧域之外，那些不被现世接纳的存在常年汇聚于此。

## 旧域

> 定位：底层 · 混沌区域 ｜ 死去世界的最终归宿

**原文**

旧域

位于底层的混沌区域，是一切死去世界的最终归宿。

混乱无序是这里永恒不变的铁律，任何时代的遗迹皆有可能在旧域内出现，其中甚至可能存放着上个纪元的遗物（见 [纪元](world-cycle.md)）。

## 层级关系

| 层级 | 区域 | 有序度 | 关键特征 |
|---|---|---|---|
| 顶层 | 群星 | 未知 | 归属于外神；时间与空间概念不复存在 |
| 上层 | 现世 | 有序 | 正在逐渐死去；非凡概念被严格封锁 |
| 中层 | 边境 | 无序 | 缓冲区域；不被现世接纳者汇聚 |
| 底层 | 旧域 | 混沌 | 一切死去世界的归宿；上个纪元遗物 |

## 区域转化

[修正值](correction.md) 以 0 为界：**高于 0 稳定、等于 0 出现不稳定预兆并形成与边境的通路、低于 0 则崩溃并向旧域沉没**，并直接决定现世、边境、旧域之间的相互转化。原文中的实例：

- 「[震怒之日](timeline.md)」：现世的修正值再一次跨越 0 的界限，第二次冲击降临，旧王复苏。
- 「[千禧陆沉](timeline.md)」：海量源质涌入现世，骤降的修正值使现世部分区域向边境转化。
- [联合国](timeline.md) 成立目的之一：维持现境内部修正值的稳定。

## 阻止区域间通行的方式

**封闭的手段是[源质反应堆](reactor.md)**：

反应堆**以[辉石](essence.md)为动力，烧掉该区域内的源质** → 该区域**源质浓度下降** → **区域修正值回升为正值** → 天然裂隙**失去形成条件而闭合**。

这与天然裂隙"形成于修正值降至 0 的地带"正好是同一原理的**反向运用**。

```
封锁一条通路
   ├─ 需要：源质反应堆（以辉石为动力，烧掉区域内的源质，把修正值抬为正值）+ 常驻人力（术士）
   └─ 效果：暂时有效
        └─ 一旦供能中断 → 修正值重新降至 0 → 重新生成自然通路
```

## 通路类型

| 通路 | 形态 | 稳定性 | 主要使用者 |
|---|---|---|---|
| 天然裂隙 | 修正值降至 0 的地带自然形成的接缝 | 低，位置不定 |非法术士、扭曲者 |
| 人工门径 | 以[炼金学](alchemy.md)与辉石能量维持的定向通路 | 高，但昂贵且需持续供能 | 合法术士 |

## 尚未展开

- **源质反应堆的数量与部署成本**：[源质反应堆](reactor.md)烧掉区域内源质、把修正值抬为正值，但现世究竟有多少台反应堆、由谁提供与审批，尚未确立（并与「[遗物](artifact-relic.md) 由哪一方逆向工程」同题）。

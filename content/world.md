## 群星

> 定位：顶层 · 未知区域 ｜ 归属[外神](outer-gods.md)的未知区域

**原文**

群星

位于顶层、拥有无限可能的未知区域。

群星是一切源质的根源，无穷无尽的源质从此流溢向现世、边境与旧域，时间与空间的概念在此不复存在。

## 现世

> 定位：上层 · 有序区域 ｜ 正在逐渐死去的世界

**原文**

现世

位于上层、正在逐渐死去的有序世界。

作为抵御旧域侵蚀的最后战线，任何有关于非凡的信息在现世被严格封锁，各势力以此维系着文明的未来。

## 边境

> 定位：中层 · 无序区域 ｜ 现世与旧域的缓冲区

**原文**

边境

位于中层、抵御旧域侵蚀的缓冲区域。

作为抵御旧域侵蚀的缓冲区域，边境因不可逆转的源质扭曲而诞生，那些不被现世接纳的存在皆汇聚于此。

## 旧域

> 定位：底层 · 混沌区域 ｜ 死去世界的最终归宿

**原文**

旧域

位于底层、归于永恒混沌的无序世界。

作为一切死去世界的最终归宿，旧域汇集了它们生前的最后残余，任何时代的文明遗迹皆可能在此被发现。


## 层级关系

| 层级 | 区域 | 秩序 | 特征 |
|---|---|---|---|
| 顶层 | 群星 | 未知 | 未知领域；拥有无限可能的未知领域；时空的概念不复存在 |
| 上层 | 现世 | 有序 | 逐渐死去；抵御旧域侵蚀的最后战线，非凡概念被严格封锁 |
| 中层 | 边境 | 无序 | 边缘世界；现世与旧域间的缓冲区域，不被现世接纳者汇聚 |
| 底层 | 旧域 | 混沌 | 终焉之地；所有混乱与纷争的发源地，一切死去世界的归宿 |

## 区域转化

[修正值](correction.md) 以 0 为界：

**高于 0 稳定、等于 0 出现不稳定预兆并形成与边境的通路、低于 0 则崩溃并向旧域沉没**，并直接决定现世、边境、旧域之间的相互转化。原文中的实例：

- 「[震怒之日](day-of-wrath.md)」：诸神为重塑原初律法发动的神战唤起了旧域深处四位沉寂的旧王，神话时代就此结束，“第二次冲击”降临。
- 「[千禧陆沉](millennium-sinking.md)」：“终末之环”融毁所释放的狂暴源质永久地撕裂了南极区域现世、旧域与边境间的界限，“第三次冲击”降临。

## 区域间通行的方式

| 通路 | 形态 | 稳定性 |
|---|---|---|
| 天然裂隙 | 修正值降至 0 的地带自然形成的接缝 | 低，位置不定 |
| 人工门径 | 以**[源质反应堆](reactor.md)**维持的定向通路 | 高，但昂贵且需持续供能 |

**[源质反应堆](reactor.md)**：

反应堆**以[辉石](essence.md)为动力，烧掉该区域内的源质** → 该区域**源质浓度下降** → **区域修正值回升为正值** → 天然裂隙**失去形成条件而闭合**。

这与天然裂隙"形成于修正值降至 0 的地带"正好是同一原理的**反向运用**。

```
封锁一条通路
   ├─ 需要：源质反应堆（以辉石为动力，烧掉区域内的源质，把修正值抬为正值）+ 常驻人力（术士）
   └─ 效果：暂时有效
        └─ 一旦供能中断 → 修正值重新降至 0 → 重新生成自然通路
```

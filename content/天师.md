**原文**

【天师】（摘自 [新神州](新神州.md)）

随着某位被称为“天师”年轻术士的出现，神州当下的动荡局面首次迎来了转折。

他以恐怖的战略思维在指挥抗击“重樱帝国”的战斗中初显锋芒，用一次次几乎不可能的胜利折服了原本各自为战的禁军残部。

在他的指引下，一支能与“重樱帝国”相抗衡的武装随之形成，持续八年的“神州统合战争”就此爆发。

战后，最后的一百零八位禁军意图将指引他们走向胜利的年轻“天师”推举为君临神州的下一位“龙帝”.

可出乎他们预料的是，“天师”却平淡地拒绝了这份令无数人趋之若鹜的请求。

他选择将主导神州未来的权力交还给构成这个古老国度的每一位个体，自身则深入旧域，以此寻求拯救现世的方式。

从此刻起，与“旧神州”截然不同的“新神州”就此成立。

## 0. 定位

打赢了神州统合战争，拒绝了龙帝之位，然后一个人走进了旧域。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| **姓名 / 常用称呼** | **天师**（旧称「导师」）；本名原文未提 |
| **种族** ⟂ | 人类 |
| **年龄 / 所属时代** ⟂ | 二十世纪三十年代末活跃；原文只写「年轻」 |
| **出身地** ⟂ | 神州——[旧神州](旧神州.md) 崩后的五百年乱世之中 |
| **当前所属势力** | 无。战后不称帝、不任职，只身进入 [旧域](四层世界.md#旧域) |

## 2. 位阶

| 位阶 | 所属界 | 与律法的关系 | 人格稳定 |
|---|---|---|---|
| **7 阶** | 创造界 | 完全融合 | 低 |

- **为什么卡在创造界**：原文把他压在两个端点之间。一头是折服五百年乱世里打出来的禁军残部、并指挥八年战争；另一头是他还能对话、能拒绝、能自己决定走进旧域——原型界没有「拒绝」这个动作（见 [能力体系](力量体系.md) 的红线）。低于 7 阶撑不起前者，高到原型界就没有后者。
- **「低」不等于失常**：他的稳是被磨平的那种稳——不是没有情绪，是已经没有没被推演过的未来可期待。纸面上这一栏就是「低」。

## 3. 律法

| 项 | 内容 |
|---|---|
| **律法名称** | **推演** |
| **权能** | 在源质回路供能范围内，把已知条件展开成若干条可能走向，并看清每条走向上的关键节点 |
| **边界** | 只能推演他掌握的信息——**信息有缺口的地方，推出来的就是空线或错线**；他得到的是「可能」，不是「必然」 |
| **触发条件 / 代价** | 推演越深越久，源质消耗越大；看得越多，越分不清「推演过的那条线」和「正在发生的这条线」 |
| **是否已知其来源** | 原初律法碎片（默认） |

原文只给了他两样东西：**「恐怖的战略思维」** 和 **「一次次几乎不可能的胜利」**。这两句不解释成「他看得见」，就没法解释——一个年轻术士凭什么在八年里每一仗都押对。

- **「几乎不可能」是关键**：他不是必胜。推演把胜率从个位数拉到能打，剩下的仍然是禁军拿命填的。
- **代价对应结局**：把每条路都看完的人，不会觉得龙帝之位是个选择。他拒绝时「平淡」，是因为他已经看过接受的那一页。
- **他的源质从哪来**：战场上靠 [辉石](辉石.md) 补给，常年处在接近空虚的边缘——推演吃掉的东西比战斗多。这也是他不能在现世久留的另一半原因。

## 4. 社会身份（帷幕内外）

| 项 | 内容 |
|---|---|
| **合法 / 非法** | 合法术士——战时被禁军拥戴，战后未被清算 |
| **帷幕立场** | 维护——没有向民间公开任何非凡信息，把权力交还给个体而不是自己收下 |
| **公开身份**（凡人面前） | 无。原文没给他任何凡人可查的头衔 |
| **非凡信息暴露程度** | 圈内公开——禁军与封王知道他是什么；民间只知道「天师」两个字 |

| 项 | 内容 |

## 7. 关系网

| 关系对象 | 类型 | 律法层面的牵连 |
|---|---|---|
| **一百零八位禁军** | 同阵营 | 不是被律法拖到一起的——是他赢给他们看，他们才跟；最后也是他们把他推上龙帝之位 |
| **四位封王** | 旧识 / 敌对 | 封王要禁军撤退，禁军拒绝；北境王遇刺是整场战争的引线 |
| **[帝国轴心](新神州.md)** | 敌对 | 神州统合战争的对手，1945 年溃败 |
| **[龙帝](旧神州.md)** | 名号层面继承 | 一百零八位禁军要给他的，正是龙帝的名号；他不要 |

> 原文里他和谁都不是被律法「吸引」到一起的——这在他身上是**反例**：一段完全由选择构成的关系网。要用它当主角的对照，就别给他补宿命。

## 待定

1. **名号**：正文一律「天师」，「导师」是旧称。[角色卡模板](角色卡模板.md) 的时代轴仍写「导师拒绝称帝」，要不要一并改。
2. **律法**：「推演」是整理层提案，原文没有这个权能。要换就整节重写。
3. **位阶**：7 阶是提案。想让他更「人」一点就降到 6 阶（形成界），代价是「独自深入旧域还能不能回来」这一笔就没了。
4. **种族**：原文只写「年轻术士」，现在填的是人类。
5. **结局**：原文只写「深入旧域，以此寻求拯救现世的方式」，没写他回来没有。这条留空。

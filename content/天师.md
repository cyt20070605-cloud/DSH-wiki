【天师】

## 0. 定位

新神州的至强者，一百零八禁军之主，以人类之躯比肩龙帝的九阶术士，在神州统合战争后深入旧域，至今下落不明。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| **姓名 /代号** | **未知**、**天师**； |
| **种族** ⟂ | 人类 |
| **年龄 / 所属时代** ⟂ | 二十世纪三十年代末活跃；原文只写「年轻」 |
| **出身地** ⟂ | 神州——[旧神州](旧神州.md) 崩后的五百年乱世之中 |
| **当前所属势力** | 新神州，战后拒绝称帝，只身进入 [旧域](四层世界.md#旧域) |

## 3. 律法

| 项 | 内容 |
|---|---|
| **律法名称** | **天衍易术** |
| **权能** | 把世界的未来展开成若干条可能走向，并推算出每条走向上的关键节点 |
| **边界** | 他得到的是需要以行动实现的「可能」，而非仅需坐享其成的「必然」 |
| **触发条件 / 代价** | 对未来的推演需要规模空前的源质供应，这也是他选择深入旧域而非驻守现世的主要原因 |
| **是否已知其来源** | 原初律法碎片（默认） |

## 6. 所处时代

**时代（选一个，决定他能知道什么）**

| 时代 | 一句话 |
|---|---|
| 黄金时代 | 世界自烧却混沌的烈火中诞生 |
| 破碎战争 · 第一次冲击 | 终末之环提前点火，前文明毁灭，原初律法分崩离析 |
| 神话时代 | 旧王扭曲历史，幸存者为律法碎片厮杀；神明成为世间顶点 |
| 震怒之日 · 第二次冲击 | 诸神为复现原初律法发动无止境神战，尽数陨落；现世深度归 0 |

| 第二次现世战争 | 帝国轴心远征；神州统合战争；"天师"拒绝称帝 |

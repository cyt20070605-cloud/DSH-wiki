**原文**

【源质反应核心】

作为对终末之环逆向工程的产物，源质反应核心虽然复现了“终末之环”燃烧源质释放能量的主要功能，可机组的效能却不及“终末之环”的哪怕千万分之一。

源质反应核心无法像“终末之环”那样持续燃烧从“群星”涌入“现世”的源质，在无需任何外部能源供应的情况下永久运行，而是需要源源不断的“辉石”供应。

当“终末之环”在“千禧陆沉”事件中融毁、现世的物理规则因不断涌入源质而濒临崩溃时，规模不同的源质反应核心便成为了维持现世深度的临时措施。

可现世内的辉石储量终归是有限的，一旦辉石耗尽，现世就将因物理规则的崩溃而沉入旧域。

## 源质反应核心的特征

**它是终末之环的仿制品：以[辉石](源质.md)为燃料，燃烧区域内源质并释放能量，维持区域的物理规则稳定，并使该区域[深度](深度体系.md)维持为正。**

## 源质反应核心的运作原理

```
投入：辉石（燃料）
  └─► 燃烧区域内源质并释放能量
        └─► 源质反应程度降低、区域物理规则稳定、深度值稳定为正值
              └─► ① 低源质环境 —— 限制术士在现世内部的活动
```

## 与终末之环间的区别

| | [终末之环](封印物.md)（原件） | 源质反应核心（仿制品） |
|---|---|---|
| 燃料 | 无需外部能源，**自行**抽取涌入现世内部的源质 | **需以[辉石](源质.md)为燃料** |
| 燃烧范围 | **整个现世** | 仅**区域**级：城市／行省／国度 |
| 功效 | 基准 | **不及终末之环的千万分之一** |
| 现况 | 在“千禧陆沉”事件中融毁 | 维系现世物理规则的**最后手段** |

## 源质反应核心的重要性

“千禧陆沉”让“终末之环”融毁，现世内部的源质只增不减，物理规则濒临崩溃。**不同规模的源质反应核心成为维持现世物理规则稳定的最后手段。**

但这是**倒计时**，因为**现世的辉石储量有限。一旦耗尽，现世就将因物理规则的崩溃而沉入旧域。**

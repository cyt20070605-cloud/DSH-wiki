> **补充设定**：源质 → 辉石 → 炼金产物 → 术士装备的产业链展开；与原始设定冲突处以原文为准。

## 出发点（来自原文）

- [源质](essence.md)：来自高维的纯粹能量，具有扭曲现实的功效，广泛分布于世界每一个角落。
- **辉石**：高浓度的源质会与环境中的物质发生反应而形成，散发着蓝色光芒，可以为术士提供大量经过高度浓缩的源质（[原文](essence.md)语）。它**同时维系着整个世界的能源供应**——两项属性共同支撑了本页的产业链。
- [炼金学](alchemy.md)：对遗物进行系统性研究后总结而出的理论；[炼金武装](alchemy-arms.md) 是其最重要的衍生物。
- [复兴时代](timeline.md)：术士需要工业化生产带来的大量炼金产物与非凡材料，各国则需要术士为其提供抵御[旧域](world.md#旧域)存在的力量——**术士与国家势力深度绑定**。

## 关键前提：源质与辉石是两种东西

> 源质是源自高维的神秘能量，具有扭曲现实的功效，它可以被术士的律法调用于扭曲现实的进程，**却无法被直接开采**；可一旦源质与物质结合，既能为术士提供浓缩源质、又**维系现世内部能源供应**的辉石将会形成。作为稳定物质形态的存在，**开采辉石并不会对区域修正值造成影响**。

这道边界容易被误写：

| | 源质 | 辉石 |
|---|---|---|
| 形态 | 高维能量 · 游离态 | 稳定物质形态 |
| 可否开采 | **不可** | **可** |
| 可否储运 | 不可 | 可 |
| 可否结算 | 不可 | 可（硬通货） |
| 用途 | 被[律法](law.md)调用以扭曲现实 | 能源供应、术士的浓缩源质来源、炼金原料 |
| 与[修正值](correction.md) | 浓度决定修正值 | **开采不影响修正值** |

**由此产生一个重要的结构性事实**：

> **术士的力量无法被囤积，现世的能源可以被囤积。**

因为术士调用的是游离态源质——它就地存在；而辉石可以被开采、运输、使用。所以真正能成为货币、能积累、能被垄断的是辉石，而不是力量本身。

## 产业链五段

| 环节 | 输入 | 输出 | 关键约束 |
|---|---|---|---|
| ① 凝结 | 游离态源质 + 环境物质 | **辉石**（蓝光） | 自然发生，人类无法加速；需高浓度源质环境，产地受限 |
| ② 开采 | 辉石矿脉 / 凝结区 | 粗辉石 | 依赖[通行](world.md#四层通行)能力与领地控制；**不影响区域修正值** |
| ③ 炼制 | 辉石 + 遗物逆向工程成果 | 炼金产物、非凡材料 | 知识与工艺壁垒极高 |
| ④ 装配 | 炼制产物 + 强大特质材料 | [炼金武装](alchemy-arms.md) | **仅适合术士使用**（门槛：身体机能与精神） |
| ⑤ 部署 | 炼金武装 + 术士 | 抵御旧域存在的力量 | 各国以国家契约与辉石供应绑定术士 |

## 辉石为什么是硬通货

1. **双重身份**：它既是能源（"维系着整个世界的能源供应"），又是工业原料，且**可直接为[术士](sorcerer.md)提供高度浓缩的源质**（见[源质回路](sorcerer.md#核心机制-为什么越高环越难稳定人格)）——一种既能供能、又能供源质、还能造武器的东西，天然成为结算单位。
2. **可囤积**：它是稳定物质形态，可以开采、运输、储藏、结算——而游离态源质完全做不到这一点。
3. **产地集中**：只在源质浓度足够高的地方凝结，因此**地缘即定价权**。
4. **不可替代**：术士体系与现代非凡体系都建立在它之上，[复兴时代](timeline.md)的"工业革命"本身就是以炼金学为核心的。
5. **它还是[帷幕工程](history-official.md)的燃料**：[源质反应堆](artifact-relic.md)由辉石供能。这意味着各国官方维持"现世低源质环境"的装置，烧的正是**他们自己配给出去的**同一种东西——**能源、术士的源质来源、以及限制术士的手段，三者共用同一份储备**。

## 统一单位：联合国遗产

> 辉石**有统一单位**，且这套标准是**联合国的遗产**——前联合国时代确立的国际标准至今沿用。

这带来一个有意味的张力（与"维稳网无中心结构"并存）：

```
联合国（1945–2012）确立辉石计量标准
        ↓ 解体
标准仍在沿用 ← 因为跨境贸易离不开它
        ↓
但已无人有权维护/修订它
        ↓
各国各自为政（维稳网无中心结构）→ 标准逐渐失真，黑市按产地折价
```

## 不存在人造辉石

> **凝结是自然过程，人类只能采，不能造。**

现世能做到的只有**替代**：[炼金学](alchemy.md) 造出的非凡材料与 [炼金武装](alchemy-arms.md) 在**装备用途**上是辉石的替代路径 —— 但它们**不能供能、不能结算**。

原因就在辉石的四条硬通货理由里：它的货币性来自**同时是能源与原料**，而炼金材料只占了后一半。

| | 天然辉石 | 炼金材料 |
|---|---|---|
| 作为装备原料 | 可 | **可** |
| 供能 | 可 | **不可** |
| 结算（通货） | 可 | **不可** |

> 这也正是「**产地集中 → 地缘即定价权**」得以继续成立的原因（见上方「辉石为什么是硬通货」）。

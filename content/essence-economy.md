> **补充设定**：源质 → 辉石 → 炼金产物 → 术士装备的产业链展开；与原始设定冲突处以原文为准。

## 出发点（来自原文）

- [源质](essence.md)：来自高维的纯粹能量，具有扭曲现实的功效，广泛分布于世界每一个角落。
- **辉石**：高浓度的源质会与环境中的物质发生反应而形成，散发着蓝色光芒，"其存在维系着整个世界的能源供应"。
- [炼金学](alchemy.md)：对遗物进行系统性研究后总结而出的理论；[炼金武装](alchemy-arms.md) 是其最重要的衍生物。
- [复兴时代](timeline.md)：术士需要工业化生产带来的大量炼金产物与非凡材料，各国则需要术士为其提供抵御[旧域](world.md#旧域)存在的力量——**术士与国家势力深度绑定**。

## 关键前提：源质与辉石是两种东西

> 源质是源自高维的神秘能量，具有扭曲现实的功效，它可以被术士的律法调用于扭曲现实的进程，**却无法被直接开采**；可一旦源质与物质结合，维系现世内部能源供应的辉石将会形成。作为稳定物质形态的存在，**开采辉石并不会对区域修正值造成影响**。

这道边界容易被误写：

| | 源质 | 辉石 |
|---|---|---|
| 形态 | 高维能量 · 游离态 | 稳定物质形态 |
| 可否开采 | **不可** | **可** |
| 可否储运 | 不可 | 可 |
| 可否结算 | 不可 | 可（硬通货） |
| 用途 | 被[律法](law.md)调用以扭曲现实 | 能源供应、炼金原料 |
| 与[修正值](correction.md) | 浓度决定修正值 | **开采不影响修正值** |

**由此产生一个重要的结构性事实**：

> **术士的力量无法被囤积，现世的能源可以被囤积。**

因为术士调用的是游离态源质——它就地存在、无法开采、无法储存；而辉石可以被开采、运输、结算。所以真正能成为货币、能积累、能被垄断的是辉石，而不是力量本身。

## 产业链五段

| 环节 | 输入 | 输出 | 关键约束 |
|---|---|---|---|
| ① 凝结 | 游离态源质 + 环境物质 | **辉石**（蓝光） | 自然发生，人类无法加速；需高浓度源质环境，产地受限 |
| ② 开采 | 辉石矿脉 / 凝结区 | 粗辉石 | 依赖[通行](passage.md)能力与领地控制；**不影响区域修正值** |
| ③ 炼制 | 辉石 + 遗物逆向工程成果 | 炼金产物、非凡材料 | 知识与工艺壁垒极高 |
| ④ 装配 | 炼制产物 + 强大特质材料 | [炼金武装](alchemy-arms.md) | **仅适合非凡者使用** |
| ⑤ 部署 | 炼金武装 + 术士 | 抵御旧域存在的力量 | 各国以国家契约绑定术士 |

> 注：**没有"开采源质"这一环**——源质不可开采。第一环是**凝结**，且它是自然过程，人类只能在凝结完成后去采。

## 辉石为什么是硬通货

1. **双重身份**：它既是能源（"维系着整个世界的能源供应"），又是工业原料——一种既能供能又能造武器的东西，天然成为结算单位。
2. **可囤积**：它是稳定物质形态，可以开采、运输、储藏、结算——而游离态源质完全做不到这一点。
3. **产地集中**：只在源质浓度足够高的地方凝结，因此**地缘即定价权**。
4. **不可替代**：术士体系与现代非凡体系都建立在它之上，[复兴时代](timeline.md)的"工业革命"本身就是以炼金学为核心的。

## 统一单位：联合国遗产

> 辉石**有统一单位**，且这套标准是**联合国的遗产**——前联合国时代确立的国际标准至今沿用，本身即联合国的政治遗产之一。

这带来一个有意味的张力（与"维稳网无中心结构"并存）：

```
联合国（1945–2012）确立辉石计量标准
        ↓ 解体
标准仍在沿用 ← 因为跨境贸易离不开它
        ↓
但已无人有权维护/修订它
        ↓
各国各自为政（维稳网无中心结构）→ 标准逐渐失真，黑市按产地折价
```

也就是说：**辉石是现世唯一还在运转的"联合国制度"**，而它已经没有主人了。统一单位的具体名称与今天的维护者尚未确立。

## 各方在链条上的位置

按原文已确立的势力与格局（各国官方 + 合作派干员维稳，对抗叛离派与渗透者）：

| 主体 | 占据环节 | 说明 |
|---|---|---|
| 各国官方 | ②③⑤ | 掌握门径审批、辉石产地与术士部署，是链条的实际控制者 |
| 前先锋守望合作派 | ②的巡查与⑤的执行 | 维持现世稳定，同时巡查天然裂隙 |
| 炼金术士与工坊 | ③④ | 以[炼金学](alchemy.md)为壁垒的技术阶层 |
| 叛离派干员 / 走私者 | ②的灰色通道 | 利用天然裂隙私运辉石、[遗物](artifact-relic.md)与情报 |
| [奇幻种](race-fantasy.md) | ②的边境一侧 | 世代居于[边境](world.md#边境)，是凝结区与矿脉的原住民 |
| 旧王衍生势力 | ②③ | 四大组织的名号本身即指向产业：**永世集团**直指物与真实、欲望与度量，与企业实体最贴合；**百相熔炉协会**名号含"熔炉"，与炼制环节相合 |

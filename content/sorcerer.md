**原文**

【术士】

术士是一切执掌律法类人生物的统称。

其位阶被划分为1-9环，1环为最低阶，9环为最高阶，环的数量越高，稳定自身人格的难度也就越高。

## 要点

- **统称**：一切执掌 [律法](law.md) 的**类人生物**的统称。
- **范围**：术士是**类人生物**的位阶体系——**不限于[人类](race-human.md)**。凡形态近似人类的种族皆在此列，故[奇幻种](race-fantasy.md)、[龙裔](race-dragonkin.md) 亦可有术士。
- **位阶**：1–9 环，**1 环最低、9 环最高**。
- **代价**：环的数量越高，稳定自身人格的难度也就越高——因为**个体与律法的融合程度越深**。
- **流转**：术士死亡时，赋予其非凡能力的律法会脱离主体，直到新的 [遗物](artifact-relic.md) 形成或被其他术士融合（详见 [律法](law.md)）。

## 核心机制：为什么越高环越难稳定人格

> 律法只是一种运用源质扭曲现实的有效手段，高环术士的人格崩溃是因为源质本身对现实具有扭曲性，术士或许相较于普通人而言对源质有着更高的抗性，可一旦源质的浓度过高，其依旧存在畸变的可能性。

```
源质（高维能量 · 对现实具有扭曲性）        ← 这是根因，不是律法
   │
   ├─ 律法 = 运用源质扭曲现实的「有效手段」  ← 术士是运用者，不是承载者
   │
   └─ 抗性：术士 > 普通人（相对优势，非免疫）
          │
          └─ 源质浓度超过个体阈值 ──► 畸变（普通人、术士同样会发生）
```

三个要点：

1. **律法是手段，不是病因。** 术士之所以强，是因为掌握了调用源质的方法，而非因为体内寄宿着律法。
2. **崩溃的根因是源质自身的扭曲性。** 高环术士人格崩溃，本质是长期、大剂量调用源质后，源质对现实（含自身）的扭曲作用累积所致。
3. **抗性是相对值。** 术士比普通人耐受得多，但**没有绝对免疫**；浓度一旦超过阈值，术士一样畸变。

## 环阶的四个阶段

1–9 环并非平铺的九级台阶，而是**四个阶段**——个体与律法的关系在其中逐层改变：

> **物质界（1–3 环）→ 形成界（4–6 环）→ 创造界（7–9 环）→ 原型界（超越 9 环）**

前三阶段属于术士，第四个（原型界）不属于。完整表格、原型界的实质、位阶与类别对照，见 **[能力体系](power-system.md)**。

### 「术士」是现代体系的名字

这个名字属于**现代非凡体系**。而在它之前，同一类存在被叫作**[新神](new-gods.md)**——原始非凡体系下的执掌律法者：

| | 体系 | 途径 |
|---|---|---|
| **新神** | 原始非凡体系（[混沌时代](timeline.md) ～ 十四世纪末） | 通过教会向神明献上信仰与忠诚 |
| **术士** | 现代非凡体系（[复兴时代](timeline.md) 起） | 以[炼金学](alchemy.md)为核心 |

> **两者本质是同一类存在**，区别只在名称随体系更替而变。详见 [新神 · 祂们就是"原始体系下的术士"](new-gods.md)。

### 为什么融合越深，人格越不稳

四个阶段是同一条因果链上的四个刻度：

```
初步接触律法 → 进一步理解 → 深度融合 → 彻底超越个体性
     │              │            │            │
 人格稳定度高    稳定度中     稳定度低      人格崩解
                                    │
                          以自身为通道调用的源质浓度骤升
                                    │
                        源质本身的扭曲性持续作用于自身
```

前三个阶段里，融合得越深，个体**以自身为通道调用的源质越多**，源质本身的扭曲性也就累积得越快——崩溃由此而来，与律法无关。

> 也就是说：**位阶衡量的是"你与律法有多近"，人格的代价衡量的是"你替它承受了多少源质"。**

```
人格稳定程度
   ▲
高 │ ████ 物质界（1–3 环）
   │      ████ 形成界（4–6 环）
中 │           ████ 创造界（7–9 环）
   │                ████ 原型界（超越 9 环）
崩 │                     ████
   └──┬────┬────┬────┬────┬────┬────┬────┬────┬────┬──► 环阶
      1    2    3    4    5    6    7    8    9   超越
                                                    9 环
```

## 与修正值的关系

[修正值](correction.md) 是衡量源质反应程度的唯一方式，且同时适用于区域与个体——**抗性阈值与修正值是同一套标尺**，不必另立"耐受上限"单位：

- **区域修正值低于 0** → 该区域源质浓度过高 → 区域内一切存在面临畸变风险（对应[第三次冲击](timeline.md)"无数人因突发的源质畸变而扭曲"）。
- **个体修正值低于 0** → 该个体承受的源质浓度已超阈值 → 畸变。
- **高环术士的人格崩溃** → 同一条曲线的极端表现：以自身为通道长期高浓度暴露。

> 也就是说：**区域的无序与术士的疯狂，是同一种病在不同尺度上的表现。**

## 律法熔断

> 术士可以完全解放自身律法，进入"律法熔断"状态，以结束后一段时间内无法使用律法为代价换取短暂的实力提升，但进入"律法熔断"状态的时间越长，后续恢复所需要的时间便越长，严重时甚至将造成术士本身的死亡。

### 要点

- **性质**：术士**主动**完全**解放自身律法**，进入「律法熔断」状态。
- **收益**：换取**短暂的实力提升**。
- **代价**：熔断结束后，**一段时间内无法使用律法**。
- **递进**：进入熔断的时间越长 → 后续恢复所需时间越长 → **严重时造成术士本身的死亡**。
- **适用**：**所有环阶**的术士皆可进入熔断状态。

### 熔断针对的是「术士与律法的关系」

术士是**一切执掌[律法](law.md)类人生物的统称**——「执掌」正是这个统称的定义所在。因此原文把代价定在**律法本身**（"一段时间内无法使用律法"），而不是定在[源质](essence.md)抗性上：

```
平时：术士 ──执掌──► 律法 ──调用──► 源质 ──扭曲──► 现实

熔断：术士 ══完全解放══► 律法（全开）──► 短暂的实力提升
        │
        └─► 结束后：律法在一段时间内无法被使用
              └─► 熔断越久 → 恢复越久 → 严重时致死
```

> 也就是说：**熔断是"把律法开到全满"，而不是"让源质灌得更猛"。** 因此它是一条与人格崩解**并列**、而非从属的机制。

### 与人格崩解的区别

| | 高环术士的人格崩解 | 律法熔断 |
|---|---|---|
| 起因 | 长期、大剂量调用源质，**源质自身的扭曲性**不断累积 | 术士**主动**解放自身律法 |
| 代价形态 | 人格**崩解**，仅剩本能的神性主导 | 熔断后**一段时间无法使用律法** |
| 是否可逆 | 不可逆（见 [能力体系](power-system.md)） | **可恢复**——但熔断越久、恢复越久，严重时致死 |
| 谁会碰上 | 融合越深越容易，高环术士最先崩解 | **所有环阶**皆可主动进入 |

> 一句话：**崩解衡量的是「你替源质承受了多少」，熔断衡量的是「你把律法开到了多满」。**

## 体系两阶段

| 阶段 | 时代 | 获取非凡的途径 |
|---|---|---|
| 原始非凡体系 | [混沌时代](timeline.md) | 通过教会向神明献上信仰与忠诚，以换取通往非凡的资格 |
| 现代非凡体系 | [复兴时代](timeline.md) 起 | 以 [炼金学](alchemy.md) 为核心；术士与国家势力深度绑定 |

原文对「复兴时代」后关系的描述：术士需要工业化生产带来的大量炼金产物与非凡材料，各国则需要术士为他们提供抵御 [旧域](world.md#旧域) 存在的力量。

## 术士在现世社会的处境

**明面：按「是否在契约之内」分类。**

- **合作派**受信任并被部署——[各国官方以国家契约绑定术士](essence-economy.md)，手里握着门径审批、辉石产地与**术士部署**。
- **叛离派**被归为不稳定因素——官方用的是**行为分类**而非身份分类（[时间线](timeline.md) 记有「仅因行为模式相似而被官方归为一类」）。
- 这条线本就写在「干员分流」里，本页只是把它从"干员"扩展到**全部术士**。

**暗面：创造界另有登记与预案。**

- **形成界**是现世**骨干**（[术语索引](glossary.md) 记作"绝大部分精英术士"），被完全信任；
- **创造界**——[新神](new-gods.md)、[旧王](old-kings.md) 与**极少数传奇术士**所在的那一界——**人格稳定度低**（见 [能力体系](power-system.md)），因此各国超凡部门对这几个人另有一套**登记、隔离与"预案"**，心照不宣。
- 数量少（原文说是"极少数"）**反而使这套做法可行**。

> 也就是说：**制度在明面上普适，而真正的紧张集中在那极少数人身上。**

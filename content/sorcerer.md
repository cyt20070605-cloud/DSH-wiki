**原文**

【术士】

术士是一切利用律法扭曲现实存在的统称。

当律法被驱动时，源质的扭曲性质将同时作用于现实与术士本身，形成类似枪械后坐力的现象，律法的强度越高，对于术士的扭曲就会越强。

当术士融合律法后，一种名为“源质回路”的特殊结构将会在他们的体内形成，术士可在源质回路中预先存储源质，在驱动律法时消耗源质以抵抗反作用于自身的扭曲。

随着位阶的提升，术士体内源质回路的储量将逐步增长，对驱动律法时反作用于自身扭曲的抗性也将随之提升，正因如此，由高位术士驱动的律法往往更为强大。

当源质回路中的源质消耗殆尽时，术士需要从环境或辉石内部重新吸收源质来恢复，这种状态对于术士而言是极为危险的。

一旦在源质回路空虚的情况下强行驱动律法，术士便会因为无法承受律法反作用于自身的扭曲而成为“扭曲者”。

## 要点

- **统称**：一切**利用[律法](law.md)扭曲现实**的存在的统称。
- **范围**：术士**不限于[人类](race-human.md)**，也不限于类人种族——**凡能与律法融合、并由此获得[源质回路](sorcerer.md#核心机制-为什么越高环越难稳定人格)者皆在此列**，故[奇幻种](race-fantasy.md)、[龙裔](race-dragonkin.md) 亦是术士。
- **位阶**：1–9 环，**1 环最低、9 环最高**。
- **代价**：环的数量越高，稳定自身人格的难度也就越高——因为**个体与律法的融合程度越深**。
- **后坐力**：驱动律法时，源质对现实的扭曲会**同时**作用于术士自身；**律法越强，反噬越强**，术士靠[源质回路](sorcerer.md)中预存的源质抵抗它。
- **扭曲者**：[源质回路](sorcerer.md)空虚时**强行驱动律法** → 无法承受反作用扭曲 → 成为**扭曲者**（原文只给出这一条成因，未说明其是否仍保有自我意识）。
- **流转**：术士死亡时，赋予其非凡能力的律法会**重新转化为碎片**，直到它们**与新的术士或 [遗物](artifact-relic.md) 融合**（详见 [律法](law.md)）。

## 核心机制：为什么越高环越难稳定人格

> 律法只是一种运用源质扭曲现实的有效手段，高环术士的人格崩溃是因为源质本身对现实具有扭曲性，术士或许相较于普通人而言对源质有着更高的抗性，可一旦源质的浓度过高，其依旧存在扭曲的可能性。

```
源质（高维能量 · 对现实具有扭曲性）
   │
   术士 ──利用──► 律法 ──扭曲──► 现实
   │                │
   │                └─► 反噬：同一份扭曲同时作用于术士自身（类似枪械后坐力）
   │                          │
   │                          ├─► 源质回路消耗预存的源质 → 抵抗反噬
   │                          │        └─► 回路耗尽 → 从环境或辉石重新吸收
   │                          │
   │                          └─► 回路空虚时强行驱动律法 ──► 扭曲者
   │
   └─ 抗性：术士 > 普通人（相对优势，非免疫）
          │
          └─ 源质浓度超过个体阈值 ──► 扭曲（普通人、术士同样会发生）
```

> 注意：**律法与术士是不可分离的**——源质回路正是**融合律法的副产物**，没有融合就没有回路，也就没有那份抵抗反噬的手段。**但反噬不是律法带来的**——它来自**源质**对现实的扭曲性，律法只是把这份扭曲引到自己身上的用法：**律法越强，反噬越强**。

四个要点：

1. 术士之所以强，是因为能**利用律法扭曲现实**——而驱动律法的代价，是源质的扭曲**同时反作用于术士自身**（原文称"类似枪械后坐力"）。

2. 这份反噬由**源质回路中预存的源质**承担：储量足以缓冲时，术士只受"消耗"；**回路空虚时仍强行驱动，就以自身承担反噬**——成为**扭曲者**。原文只把「回路空虚时强行驱动律法」列为成为扭曲者的成因；而[修正值](correction.md) 那条曲线（源质浓度超过个体阈值 → 扭曲）度量的是**长期累积暴露**。两者是同一种病（源质的扭曲性）在**急性反噬**与**长期累积**两个尺度上的表现。

3. 高环术士人格崩溃，本质是长期接触源质后，源质对现实（含自身）的扭曲作用累积所致。

4. 术士比普通人耐受得多，但**没有绝对免疫**；浓度一旦超过阈值，术士一样扭曲。

> 换句话说：**位阶衡量的是"你与律法有多近"，反噬衡量的是"你替它承受了多少源质"。**

## 环阶的四个阶段

1–9 环并非平铺的九级台阶，而是**四个阶段**——个体与律法的关系在其中逐层改变：

> **物质界（1–3 环）→ 形成界（4–6 环）→ 创造界（7–9 环）→ 原型界（超越 9 环）**

前三阶段属于术士，第四个（原型界）不属于。完整表格、原型界的实质、位阶与类别对照，见 **[能力体系](power-system.md)**。

### 「术士」是现代体系的名字

这个名字属于**现代非凡体系**。而在它之前，同一类存在被叫作**[新神](new-gods.md)**——原始非凡体系下的执掌律法者：

| | 体系 | 途径 |
|---|---|---|
| **新神** | 原始非凡体系（[混沌时代](timeline.md) ～ 十四世纪末） | 通过教会向神明献上信仰与忠诚 |
| **术士** | 现代非凡体系（[复兴时代](timeline.md) 起） | 以[炼金学](alchemy.md)为核心 |

> **两者本质是同一类存在**，区别只在名称随体系更替而变。详见 [新神 · 祂们就是"原始体系下的术士"](new-gods.md)。

### 为什么融合越深，人格越不稳

四个阶段是同一条因果链上的四个刻度：

```
初步接触律法 → 进一步理解 → 深度融合 → 彻底超越个体性
     │              │            │            │
 人格稳定度高    稳定度中     稳定度低      人格崩解
                                    │
                          驱动的律法越强 → 单次反噬越重
                                    │
                    源质本身的扭曲性持续作用于自身、逐层累积
```

前三个阶段里，融合得越深，个体驱动的[律法](law.md)就越强：**单次反噬更重、需要的缓冲更多，而累积暴露也更多** —— 崩溃由此而来，与律法本身无关，成因始终是**源质的扭曲性**。

> 也就是说：**位阶衡量的是"你与律法有多近"，反噬衡量的是"你替它承受了多少源质"。**

> 四阶段的**人格稳定度曲线**见 [能力体系 · 为什么融合越深，人格越不稳](power-system.md#为什么融合越深-人格越不稳)。

## 与修正值的关系

[修正值](correction.md) 是衡量源质反应程度的唯一方式，且同时适用于区域与个体——**抗性阈值与修正值是同一套标尺**，不必另立"耐受上限"单位：

- **区域修正值低于 0** → 该区域源质浓度过高 → 区域内一切存在面临扭曲风险（对应[第三次冲击](timeline.md)"无数人因修正值突破 0 的界限而扭曲"）。
- **个体修正值低于 0** → 该个体承受的源质浓度已超阈值 → 扭曲（原文另把「[源质回路](sorcerer.md)空虚时强行驱动律法」列为成为[扭曲者](sorcerer.md#要点)的成因）。
- **高环术士的人格崩溃** → 同一条曲线的极端表现：**驱动的律法更强、单次反噬更重**，再叠加长期累积暴露。

> 也就是说：**区域的无序与术士的疯狂，是同一种病在不同尺度上的表现。**

## 律法熔断

> 术士可以完全解放自身律法，进入"律法熔断"状态，以结束后一段时间内无法使用律法为代价换取短暂的实力提升，但进入"律法熔断"状态的时间越长，后续恢复所需要的时间便越长，严重时甚至将造成术士本身的死亡。

### 要点

- **性质**：术士**主动**完全**解放自身律法**，进入「律法熔断」状态。
- **收益**：换取**短暂的实力提升**。
- **代价**：熔断结束后，**一段时间内无法使用律法**。
- **递进**：进入熔断的时间越长 → 后续恢复所需时间越长 → **严重时造成术士本身的死亡**。
- **适用**：**所有环阶**的术士皆可进入熔断状态。

### 熔断针对的是「术士与律法的关系」

术士是**一切利用[律法](law.md)扭曲现实存在的统称**——「利用律法扭曲现实」正是这个统称的定义所在。因此原文把代价定在**律法本身**（"一段时间内无法使用律法"），而不是定在[源质](essence.md)抗性上：

```
平时：术士 ──融合──► 律法 ──调用──► 源质 ──扭曲──► 现实

熔断：术士 ══完全解放══► 律法（全开）──► 短暂的实力提升
        │
        └─► 结束后：律法在一段时间内无法被使用
              └─► 熔断越久 → 恢复越久 → 严重时致死
```

> 也就是说：**熔断是"把律法开到全满"，而不是"让源质灌得更猛"。** 因此它是一条与人格崩解**并列**、而非从属的机制。

### 与人格崩解的区别

| | 高环术士的人格崩解 | 律法熔断 |
|---|---|---|
| 起因 | 长期、大剂量调用源质，**源质自身的扭曲性**不断累积 | 术士**主动**解放自身律法 |
| 代价形态 | 人格**崩解**，仅剩本能的神性主导 | 熔断后**一段时间无法使用律法** |
| 是否可逆 | 不可逆（见 [能力体系](power-system.md)） | **可恢复**——但熔断越久、恢复越久，严重时致死 |
| 谁会碰上 | 融合越深越容易，高环术士最先崩解 | **所有环阶**皆可主动进入 |

> 一句话：**崩解衡量的是「你替源质承受了多少」，熔断衡量的是「你把律法开到了多满」。**

## 术士在现世社会的处境

**明面：按「是否在契约之内」分类。**

- **合法术士**受信任并被部署——[各国官方以国家契约绑定术士](essence-economy.md)，手里握着门径审批、辉石产地与**术士部署**。
- **非法术士**被归为不稳定因素——官方用的是**行为分类**而非身份分类（[时间线](timeline.md) 记有「仅因行为模式相似而被官方归为一类」）。

**暗面：创造界另有登记与预案。**

- **形成界**是现世**骨干**（[术语索引](glossary.md) 记作"绝大部分精英术士"），被完全信任；
- **创造界**——[新神](new-gods.md)、[旧王](old-kings.md) 与**极少数传奇术士**所在的那一界——**人格稳定度低**（见 [能力体系](power-system.md)），因此各国超凡部门对这几个人另有一套**登记、隔离与"预案"**，心照不宣。
- 数量少（原文说是"极少数"）**反而使这套做法可行**。

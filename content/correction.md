**原文**

【深度体系】

以零为分界线，深度是判定区域类型的唯一方式。

深度高于0时，该区域的物理规则较为稳定，位于现世；
深度等于0时，该区域的物理规则逐渐失衡，位于边境；
深度低于0时，该区域的物理规则彻底崩溃，位于旧域。

深度体系会对区域产生极大的影响，现世、边境、旧域之间的相互转化与之密切相关。

## 深度与修正值：同一把尺，两个刻度

原文只给了**深度**的定义，但描述具体事件时用的却是**修正值**——两者不是同一个词，也不该混用：

| | 深度 | 修正值 |
|---|---|---|
| 量的是谁 | **区域** | **个体**（人、术士、封印物等具体存在） |
| 回答的问题 | 这片地方属于现世、边境还是旧域 | 这个存在被源质扭曲到了什么程度 |
| 刻度 | 以 0 为界：正为现世、零为边境、负为旧域 | 与深度**同一套标尺**，同样以 0 为界 |
| 典型写法 | 「现世的**深度**正式跨越 0 的界限」 | 「无数人因**修正值**突破 0 的界限而扭曲」 |

**两者的关系**：

- **同一把尺，不同的对象。** 深度是量在**地图**上的读数，修正是量在**人**身上的读数——不能拿其中一个去描述另一个的对象。
- **区域先动，个体跟着动。** 区域的深度一旦跌破 0，身处其中者就开始承受扭曲，修正值随之被推过 0 的界限；这正是第三次冲击里「无数人因修正值突破 0 的界限而扭曲」的机制。
- **术士的耐受同样用修正值计量。** [源质抗性](sorcerer.md)的阈值与修正值同一套标尺：位格越高、阈值越宽，但**没有绝对免疫**。

> 一句话：**深度判地方，修正值判人。**

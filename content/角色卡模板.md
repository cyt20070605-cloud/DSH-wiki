## 2. 位阶

| 位阶 | 所属界 | 与律法的关系 | 人格稳定 |
|---|---|---|---|
| 　 | 物质界 / 形成界 / 创造界 / 原型界 | | 高 / 中 / 低 / 崩解 |

- **1–3 阶 = 物质界**：初步接触律法，人格稳定**高**。
- **4–6 阶 = 形成界**：深入理解，人格稳定**中**。
- **7–9 阶 = 创造界**：完全融合，人格稳定**低**。
- **超越 9 阶 = 原型界**：不再是"个体与律法的关系"，**存在本身即成律法的尺度**；人格**崩解**，只剩本能的神性主导。

> **写卡红线**：原型界不是"更强的九阶"。进了原型界，这个角色就**不再是人**了——没有动机、没有关系、没有台词，只有本能。想写一个能对话的角色，位阶上限是 **9 阶**。
>
> **旧王特例**：旧王身在创造界（7–9 阶），但实力接近次位外神——因为祂们**仍是个体**，没跨过那道界限。这是一处明写的"错位"，可以借用，但不能批量复制。

- **非术士角色**（平民、未融合律法者）：此栏填「无」。

## 3. 律法

| 项 | 内容 |
|---|---|
| **律法名称** | |
| **权能** | |
| **边界** | |
| **触发条件 / 代价** | |
| **是否已知其来源** | 原初律法碎片（默认）/ 未知 |

1. **律法碎片是守恒的**。所有碎片都有重组为「原初律法」的本能，所以**非凡存在之间天然互相吸引**——你的关系网不是巧合，是规律（详见第 9 节）。
2. **权能必须有边界**。律法不是许愿机，是「调用源质扭曲现实的**权限**」——权限就有范围。

| **公开身份**（凡人面前） | |

**现世的基本状态**：位于上层、**正在逐渐死去**的有序世界，作为抵御旧域侵蚀的**最后战线**，任何涉及非凡领域的信息在现世被**严格封锁**。
- 术士不得在公众面前利用律法扭曲现实。
- 奇幻种须在公众面前隐藏自身非人特征。
- 任何超越当今时代的科技不可为人所知。

## 7. 关系网

| 关系对象 | 类型 | 律法层面的牵连 |
|---|---|---|
| | 同阵营 / 敌对 / 旧识 / 债主 / 血亲 | 碎片相互吸引 → 写清"为什么偏偏是他们撞上" |

**必须有一层"物理上的吸引"**：律法碎片有重组本能，所以非凡存在之间总是相互吸引。任何一段重要关系，最好能回答一句「他们是被律法拖到一起的，还是自己走过去的」。前者有宿命感，后者有选择感——两者都要有。

## 附：五条自检

填完卡，逐条过：

1. **位阶的限制？** 9阶却情绪稳定，等于不符设定。
2. **律法的边界？** 只有权能没边界，等于没有设计。
3. **源质的来源？** 术士角色没这条，等于没有弱点。
4. **所处的环境？** 常驻现世的角色，不该去过旧域。
5. **信仰的体系？** 神话时代与当代，观念差距较大。

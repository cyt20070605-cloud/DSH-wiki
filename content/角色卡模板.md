> 用法：复制本节以下全部内容，逐项替换。带 `⟂` 的字段是**硬约束**——填错就是撞设定，不是风格问题。
> 设计原则：这张卡的每一栏都必须能由核心规则（四层世界 / 源质 / 律法 / 深度 / 术士）倒推出来。推不出来的栏，说明角色还没立住。

---

## 0. 一句话定位

> 用一句话说清「他是谁、靠什么活、卡在哪」。
> 例：一个靠辉石撑着的非法七阶术士，律法让他能听见所有人的谎言，也因此再也信不了任何人。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| **姓名 / 常用称呼** | |
| **种族** ⟂ | 人类 / 奇幻种 / 龙裔（三选一，见下方判定） |
| **年龄 / 所属时代** ⟂ | 见第 8 节时代轴 |
| **出身地** ⟂ | 现世诸国 / 文明古国 / 边境 / 旧域 |
| **当前所属势力** | |

**种族判定（不能模糊）**
- **人类**：无律法或后天融合律法。绝大多数人一辈子没碰过律法。
- **奇幻种**：祖先在破碎战争后接触破碎的原初律法而突变，**律法融在血脉里、代代传承**。生而非人特征。现世内活动受帷幕条例限制，**必须在公众面前隐藏非人特征**。
- **龙裔**：奇幻种里最特殊的一支，承的是**次位外神「绛天之龙」的血脉本身**（不是血脉里的律法）。因此**同时只能承一种特征**——要么偏权能，要么偏不朽肉体。数量极稀少，无固定聚居地。

---

## 2. 位阶与四界 ⟂

| 位阶 | 所属界 | 与律法的关系 | 人格稳定 |
|---|---|---|---|
| 　 | 物质界 / 形成界 / 创造界 / 原型界 | | 高 / 中 / 低 / 崩解 |

- **1–3 阶 = 物质界**：初步接触律法，人格稳定**高**。
- **4–6 阶 = 形成界**：深入理解，人格稳定**中**。
- **7–9 阶 = 创造界**：完全融合，人格稳定**低**。
- **超越 9 阶 = 原型界**：不再是"个体与律法的关系"，**存在本身即成律法的尺度**；人格**崩解**，只剩本能的神性主导。

> **写卡红线**：原型界不是"更强的九阶"。进了原型界，这个角色就**不再是人**了——没有动机、没有关系、没有台词，只有本能。想写一个能对话的角色，位阶上限是 **9 阶**。
>
> **旧王特例**：旧王身在创造界（7–9 阶），但实力接近次位外神——因为祂们**仍是个体**，没跨过那道界限。这是一处明写的"错位"，可以借用，但不能批量复制。

- **非术士角色**（人类平民、未融合律法者）：此栏填「无」，直接跳到第 6 节。

## 3. 律法 ⟂

| 项 | 内容 |
|---|---|
| **律法名 / 别称** | |
| **权能**（能扭曲什么） | |
| **边界**（做不到什么） | |
| **触发条件 / 代价** | |
| **是否已知其来源** | 原初律法碎片（默认）/ 未知 |

**三条必须想清楚的事**
1. **律法碎片是守恒的**。所有碎片都有重组为「原初律法」的本能，所以**非凡存在之间天然互相吸引**——你的关系网不是巧合，是物理规律（详见第 9 节）。
2. **权能必须有边界**。律法不是许愿机，是「调用源质扭曲现实的**权限**」——权限就有范围。写不出边界，说明这个角色的战斗力没设计。
3. **神明 / 术士 只是称呼差别**。原始非凡体系（神话时代～十四世纪末）里这类存在叫**神明**，走宗教仪式献信仰换资格；现代非凡体系（复兴时代起）里叫**术士**，走炼金学。**本质是同一类存在**，区别只在名称随体系更替而变。写神话时代角色就写"神明"，别混用。

## 4. 源质回路 ⟂

| 项 | 内容 |
|---|---|
| **储量**（随位阶增长） | |
| **补充方式** ⟂ | 环境吸收 / 辉石 |
| **空虚时的状态** ⟂ | |

**这条是术士类角色唯一不可省略的弱点**：
> 源质回路耗尽 → 律法扭曲现实的功效无法维系 → 必须从**环境或辉石**重新吸收 —— 这个状态对术士**极为危险**。
> 一旦在回路空虚时强行驱动律法 → 无法承受律法反作用于自身的扭曲 → 变成**扭曲者**。

所以每个术士角色都要回答：**他的辉石从哪来？断供之后他还能撑多久？** 这是最容易出戏的地方，也是最容易写出紧迫感的地方。

## 5. 战斗力校准 ⟂

按这个顺序锚定，别自由发挥：

```
上位外神（无上意志 / 轮回终末）        —— 不是角色，是环境
  ↓
次位外神（绛天之龙 / 铸形之炎 / 伏行之恶）
  ↓
旧王（创造界，实力≈次位外神）          —— 单体的天花板
  ↓
寻常九阶术士                          —— 「强者」的照妖镜
  ↓
七、八阶 / 六阶 / ... / 一阶
  ↓
炼金武装武装起来的普通人               —— 能制衡术士，但仅此而已
```

- **天灾**（神孽 / 灰潮 / 古龙）是三位次位外神的**代行者**，且是**群体性存在**——实力因个体而异，**没有统一位阶**。写天灾别给单一数字。

**两句话自检**：
- 这个角色打不打得过「寻常九阶术士」？
- 他遇上次位外神，是「战」还是「根本不是同一个量级的事」？

## 6. 社会身份（帷幕内外）⟂

| 项 | 内容 |
|---|---|
| **合法 / 非法** | 合法术士（受信任、与势力深度合作）/ 非法术士（不稳定因素、被清算） |
| **帷幕立场** | 维护 / 利用 / 无视 / 不知情 |
| **公开身份**（凡人面前） | |
| **非凡信息暴露程度** | 全公开 / 圈内公开 / 严格保密 |

**现世的基本状态**：位于上层、**正在逐渐死去**的有序世界，作为抵御旧域侵蚀的**最后战线**，任何有关非凡的信息在现世被**严格封锁**。
- 术士：不得在公众面前利用律法扭曲现实。
- 奇幻种：额外还**必须在公众面前隐藏非人特征**。
- 现世的繁华仍在吸引**帷幕之外的年轻一代奇幻种主动融入**——这是一个现成的角色动机。

## 7. 装备

| 项 | 内容 |
|---|---|
| **封印物** | 有类术士的源质回路，**源质充足时凡人也能驱动**；绝大多数被各势力严密封锁。→ 持有即意味着"来路不干净"或"身后有大势力"。 |
| **炼金武装** | 现代非凡体系的核心产物，使普通人拥有制衡术士的能力。 |
| **辉石** | 源质与物质在极端环境下融合的蓝色结晶；蓝色结晶态，亮度随内部源质浓度变化。**既是燃料也是硬通货**。 |

> 装备不是装饰。封印物自带政治后果：谁给你的、谁在追、谁能断你的货。

## 8. 时代与地理坐标 ⟂

**时代轴（选一个，决定他能知道什么）**

| 时代 | 一句话 |
|---|---|
| 黄金时代 | 世界自烧却混沌的烈火中诞生 |
| 破碎战争 · 第一次冲击 | 终末之环提前点火，前文明毁灭，原初律法分崩离析 |
| 神话时代 | 旧王扭曲历史，幸存者为律法碎片厮杀；神明成为世间顶点 |
| 震怒之日 · 第二次冲击 | 诸神为复现原初律法发动无止境神战，尽数陨落；现世深度归 0 |
| 复兴时代 | 炼金学建立，"神明"被重新审视；现代非凡体系成形 |
| 第一次现世战争 | 二十世纪初，南极冰盖深处发现空前遗迹 |
| 第二次现世战争 | 帝国轴心远征；神州统合战争；"导师"拒绝称帝 |
| 联合国诞生 | 为预防战争、联合抵御旧域而建 |
| 千禧陆沉 · 第三次冲击 | 1999 终末之环堆芯熔毁，南极被抹去 |
| 联合国解体 | 千年协定签署，帷幕计划开展，灾难成为传说 |

**深度坐标** ⟂（决定他站在哪一层）

| 深度 | 物理规则 | 所在 |
|---|---|---|
| **> 0** | 较稳定 | 现世 |
| **= 0** | 逐渐失衡 | 边境 |
| **< 0** | 彻底崩溃 | 旧域 |

> 深度对区域影响极大，三界之间**会互相转化**。一个角色的常驻深度值，等于他的日常风险等级——写在现世的人不会天天见旧域的东西；写在边境的人，家门口就可能是软的。

**现世诸国**：新神州 / 新联邦 / 欧洲共同体 / 伊塔利亚 / 莱茵联邦 / 塞纳共和国 / 法拉伦萨 / 维多利亚 / 苇原 / 北方同盟
**文明古国**：巴比伦 / 底比斯 / 旧神州 / 罗穆路斯

## 9. 关系网 ⟂

| 关系对象 | 类型 | 律法层面的牵连 |
|---|---|---|
| | 同阵营 / 敌对 / 旧识 / 债主 / 血亲 | 碎片相互吸引 → 写清"为什么偏偏是他们撞上" |

**必须有一层"物理上的吸引"**：律法碎片有重组本能，所以非凡存在之间总是相互吸引。任何一段重要关系，最好能回答一句「他们是被律法拖到一起的，还是自己走过去的」。前者有宿命感，后者有选择感——两者都要有。

---

## 10. 破绽与代价 ⟂

至少勾两项，不许全空：

- [ ] **人格崩解**：位阶越高越难稳定人格（因为与律法融合越深）。他现在靠什么撑着？
- [ ] **源质断供**：回路空虚 → 扭曲者。断供倒计时是多久？
- [ ] **律法反作用**：强行驱动时，扭曲会反噬自身。
- [ ] **身份暴露**：帷幕条例。暴露一次，代价是什么？
- [ ] **封印物来路**：持有即被追。
- [ ] **时代错位**：他信的那套体系已经没了（神明 / 旧神州 / 联合国）。

## 附：五条自检

填完卡，逐条过：

1. **位阶和人格稳定对得上吗？** 写了 8 阶却情绪稳定、思路清晰——撞设定。
2. **律法有边界吗？** 只有权能没有边界，等于没设计。
3. **辉石从哪来？** 术士角色答不出这条，等于没有弱点。
4. **他的深度坐标和环境对得上吗？** 常驻现世的角色，不该随口说见过旧域。
5. **他信的是哪套体系？** 神话时代的人不会说"术士"，复兴时代之后的人不该把神当活的神。

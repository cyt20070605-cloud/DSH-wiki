关于世界观的简述#

一个正在死去的世界，在重复的生死之间维持着平衡；而"谁有资格改写现实"，是这部设定的全部张力所在。

  • 世界是有序度递减的四层。 从有序到混沌：群星（神域）→ 现世（人所在的世界，正在逐渐死去）→ 边境（缓冲地带）→ 旧域（一切死去世界的归宿）。详见 四层世界。
  • 世界在往复中生死。 它自烈火中诞生、于旧域中死去，如此循环；如今处于第五纪元，而这一轮正在被打破。详见 纪元。
  • 「律法」是改写现实的规则总量，而它必然归一。 一切律法都有重组为「原初律法」的本能——一旦归一，世界便将死去，新的旧王 从旧域中加冕。详见 律法。
  • 「源质」是能量，「律法」是用法，「修正值」是刻度。 源质来自高维、能扭曲现实；律法决定怎么用它；修正值 衡量一个区域或个体的源质反应程度——以零为界：高于 0 稳定，等于 0 出现不稳定预兆，低于 0 崩溃并向旧域沉没。
  • 「术士」是与律法融合者。 一切与律法融合后获得源质回路的存在都叫术士，位阶 1–9 环；环数越高，越难稳定自身人格。详见 术士。
  • 「遗物」是已死世界的残骸。 世界毁灭后的文明残余散落在旧域与边境，现世的科技与工业建立在对它们的逆向工程之上。详见 遗物。

关于阅读顺序推荐#

  1. 四层世界 —— 先有一张地图：群星／现世／边境／旧域，以及它们之间怎么通行。
  2. 源质 与 律法 —— 再懂"能量"与"用法"这对最基本的概念。
  3. 修正值 —— 世界为什么会衰败、为什么会崩溃，看这一条刻度。
  4. 术士 —— 谁在改写现实，代价是什么。
  5. 时间线 —— 最后把这一切放进历史：从旧时代走到今天。

只想看"故事线"的话，读 时间线 的时代主题与三次冲击即可；新世工程 与 帷幕工程 是这条线上最重要的两个工程。

世界结构#

世界的层级划分是这部设定最底层的骨架：

层级区域有序度关键特征
顶层群星未知归属于外神；时间与空间概念不复存在
上层现世有序正在逐渐死去；非凡概念被严格封锁
中层边境无序缓冲区域；不被现世接纳者的聚集地
底层旧域混沌一切死去世界的最终归宿

四层之间并非静态：修正值 的波动会让现世与边境相互转化（第三次冲击即为一例）。

六条铁律#

  1. 律法总量守恒，所有律法都有重组为「原初律法」的本能，因此非凡存在总是相互吸引——这是一个"必然趋向终局"的世界设定。详见 律法。
  2. 一旦律法归一，原初律法降临 → 无上意志复苏 → 世界死去 → 新的 旧王 从旧域深处诞生。
  3. 修正值以零为分界：高于 0 稳定，等于 0 出现不稳定预兆、与边境间通路形成，低于 0 崩溃并向旧域沉没；同时适用于区域与个体。详见 修正值。
  4. 术士环数越高，稳定自身人格越难。详见 术士。
  5. 外神仅遵循各自本能行动，不直接干预，但力量会潜移默化影响世界进程。
  6. 旧王的使命：把现世与边境彻底沉入旧域，以复现分崩离析的原初律法。

能量与规则的双层结构#

设定把「能量」和「规则」分得很清楚：

层名词作用
能量源质来自高维的纯粹能量，具有扭曲现实的功效，广泛分布于世界每一个角落
能量凝结辉石高浓度源质与环境物质反应形成，散发蓝光，维系世界的能源供应，并为术士提供高度浓缩的源质
规则律法一切调用源质扭曲现实方式的统称，也是一切非凡特性的根源
度量修正值衡量源质反应程度的唯一方式

力量体系#

  • 术士：一切与律法融合后获得源质回路的存在的统称，位阶 1–9 环，分四界三阶段（物质界 1–3 环 / 形成界 4–6 环 / 创造界 7–9 环，超越 9 环为原型界）；与律法融合越深，越难稳定自身人格。
  • 体系两阶段：
    • 原始非凡体系（混沌时代）——通过教会向神明献上信仰与忠诚，换取通往非凡的资格。
    • 现代非凡体系（复兴时代）——以 炼金学 为核心，术士与国家势力深度绑定。
  • 装备与工具：遗物（旧域与边境内发现的神秘物品）、炼金武装（遗物的替代品）。

存在等级#

按能力体系排列，位阶与类别是一一对应的：

层级（位格）位阶类别说明
顶点原型界（超越 9 环）上位外神无上意志、轮回终末 —— 彻底超越个体性，人格崩解，仅剩本能的神性主导；无上意志显现为律法，轮回终末显现为律法的对立面
高位原型界（超越 9 环）次位外神绛天之龙、铸形之炎、伏行之恶 —— 各对应一类天灾：古龙 / 灰潮 / 恶魔
古老创造界（7–9 环）旧王以自身世界毁灭而加冕，无上意志的锋刃；实力比肩次位外神，位阶却仍在创造界；本体在旧域深处缓慢恢复，靠四大衍生势力在现世活动
秩序缔造者创造界（7–9 环）新神破碎战争后执掌律法，带来最初的秩序，陨落于震怒之日
文明威胁不定（因个体而异）天灾恶魔 / 灰潮 / 古龙 三大类；作为群体性存在，其实力有高有低、视个体而定；皆为次位外神的代行者
凡人种族物质界 – 形成界（常态）人类 / 奇幻种 / 龙裔人类多不可感知源质；奇幻种血脉传承律法。这是常态分布，不是硬上限——极少数传奇术士可跨入创造界

创造界（7–9 环）装的是仍有实体的个体：新神、旧王与极少数传奇术士；原型界（超越 9 环）只属于外神——祂们早已不是个体。

旧王是唯一的例外：位阶在创造界，实力却比肩原型界的次位外神。

本表的「层级」指位格，不指位阶。 上位与次位外神同处原型界，界内没有刻度：上位两位的动向直接决定世界的走向与往复，次位三位各负责一个具体的域。这是职能与权限的层次，不换算为战力。

用词提醒：「新世」#

「新世」是本站最容易读错的一组词：

词含义
「永诀律法之新世」「新世」工程最终要创造的世界——凌驾于此方世界之上、永诀律法。工程成功篡夺了轮回终末的权能，在原初律法崩解的瞬间其存在被确定，只是如今尚未降临
「新世」工程前文明的最终方案：原文概括为更新世界；其最终目的是创造「永诀律法之新世」——以终末之环燃烧源质的能力，间接摧毁一切以源质为存续标准的存在，并篡夺上位外神「轮回终末」的创世权能。详见 新世工程
「新世」即「永诀律法之新世」的简称，只指那个未到来的理想世界；当前世界（现世 / 边境 / 旧域）不是「新世」

时代主题#

  1. 旧时代 —— 世界自烈火中诞生、于旧域中死去，往复之中进入第五纪元；旧王行走于世间赐福，前文明因以迈入黄金年代，但其代价沉重到无法想象；为免世界死于「原初律法」之手，前文明以更新世界为号启动「新世」工程。
  2. 破碎战争 与第一次冲击 —— 终末之环被迫提前启动，链式反应撕裂维度界限，引动高天之上的烈火；以前文明的毁灭为代价，「原初律法」分崩离析，工程成功篡夺权能——一切可能性被从无上意志手中解放，「永诀律法之新世」存在被确定、尚未降临；动荡的第五纪元仍在延续，四层划分出现。
  3. 混沌时代 —— 争夺律法的厮杀，胜利者成为新神，原始非凡体系诞生。
  4. 震怒之日 与第二次冲击 —— 诸神为复现原初律法发动神战，修正值跨越 0，神明尽数陨落。
  5. 复兴时代 —— 炼金学与工业革命，术士与国家深度绑定。
  6. 两次世界大战 —— 终末之环的发现与源质武器的诞生，旧域存在以「帝国轴心」之名发起全面攻势。
  7. 联合国诞生 —— 维持修正值稳定，先锋守望成立，遗物逆向工程推动科技进步。
  8. 千禧陆沉 与第三次冲击 —— 终末之环堆芯熔毁，现世向边境转化，「千年协定」与「帷幕工程」。
  9. 联合国解体 —— 2012 年解体，先锋守望解散，干员理想破灭后分流。

完整时间线见 时间线；普通人看到的那一版见 帷幕工程。

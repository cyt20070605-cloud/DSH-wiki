修正值

核心规则核心规则核心机制更新：2026-09-15

原文

【修正值】

以零为分界线，修正值是衡量源质反应程度的唯一方式。

当修正值高于0时，该区域、个体的存在便是稳定的， 当修正值低于0时，该区域、个体的存在便是无序的。

修正值会对区域产生极大的影响，现世、边境、旧域之间的相互转化与之密切相关。

修正值大于0时现世稳定，修正值等于0时现世出现不稳定预兆，与边境之间通路形成，修正值低于0时现世崩溃，开始不可逆地向边境转化并逐步沉入旧域。

要点#

  • 定义：衡量 源质 反应程度的唯一方式。
  • 分界：以零为分界线。
  • 高于 0：该区域、个体的存在便是稳定的。
  • 等于 0：该区域出现不稳定预兆，与边境之间的通路形成。
  • 低于 0：该区域、个体的存在便是无序的——现世崩溃，开始不可逆地向边境转化并逐步沉入旧域。
  • 尺度：同时适用于「区域」与「个体」两类对象。
  • 区域效果：会对区域产生极大影响，现世、边境、旧域 之间的相互转化与之密切相关。

三个阈值#

区域尺度上，修正值以 0 为界分成三档：

修正值现世的状态
> 0稳定
= 0出现不稳定预兆；与边境之间的通路形成
< 0崩溃——开始不可逆地向边境转化，并逐步沉入旧域

也就是说：0 不是"已经出事"，而是"即将出事" —— 通路先于崩溃出现。这也是震怒之日「修正值正式跨越 0 的界限」即为第二次冲击降临之意。

四种组合#

同一套标尺，落在两类对象上就是四种情形：

对象高于 0等于 0低于 0
区域稳定不稳定预兆；与边境间通路形成无序——现世 / 边境 / 旧域 之间的相互转化与之相关
个体稳定（同一标尺，阈值同上）扭曲

原文中出现的修正值事件#

时间事件修正值变化及后果
十四世纪末震怒之日 / 第二次冲击现世的修正值正式跨越了 0 的界限，「第二次冲击」因此降临
1999 年千禧陆沉 / 第三次冲击骤降的修正值使现世部分区域向边境转化；无数人因修正值突破 0 的界限而扭曲
1945 年末联合国诞生成立目的之一：维持现境内部修正值的稳定

个体尺度的含义#

原文只用区域级实例；个体尺度按同一原理展开：

  • 源质本身对现实具有扭曲性，这是术士人格崩溃与普通区域扭曲的共同根因。
  • 个体修正值低于 0 → 该个体承受的源质浓度已超其阈值 → 扭曲。
  • 术士抗性高于普通人，但没有绝对免疫；其抗性来源是融合律法后体内形成的源质回路（回路是融合的副产物，与律法不可分离），高环术士以自身为通道长期高浓度暴露，因而最先崩解。
  • 同一套标尺：不为个体另立"耐受上限"单位——个体修正值直接用同一标尺衡量。

即：区域的无序与术士的疯狂，是同一种病在不同尺度上的表现。 曲线与四界见 能力体系。

区域与个体之间不能直接换算#

区域修正值衡量的是区域的源质浓度（背景量）；个体修正值衡量的是该个体实际承受的源质浓度是否超过其自身阈值（承受量）。环境量只是承受量的背景，不是它的换算结果。

因此：区域修正值低于 0，不等于其中的人必然扭曲。

  • 原文用的词是"面临扭曲风险"、"无数人因修正值突破 0 的界限而扭曲"——都不是"所有人"。
  • 同一片低于 0 的区域里：普通人可能扭曲、术士 可能不扭曲、长期不外出的人可能毫发无损。
  • 决定个体读数的是该个体实际承受的量，它取决于暴露时长、防护、个体阈值，以及是否调用律法。

修正值的载体是游离态源质#

源质无法被直接开采——它是高维能量，只能被律法调用于扭曲现实的进程。与物质结合后形成的辉石是稳定物质形态，开采辉石不会对区域修正值造成影响。

因此：修正值衡量的是游离态源质的反应程度，而不是辉石的储量。采集辉石不构成"抽走修正值"。

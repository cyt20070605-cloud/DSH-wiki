作为现世与旧域的缓冲区域，边境独立于现世与旧域之外，那些不被现世接纳的存在常年汇聚于此。

区域转化的判据#

修正值 以 0 为界：高于 0 稳定、等于 0 出现不稳定预兆并形成与边境的通路、低于 0 则崩溃并向旧域沉没，并直接决定现世、边境、旧域之间的相互转化。原文中的实例：

  • 「震怒之日」：现世的修正值正式跨越 0 的界限，第二次冲击降临。
  • 「千禧陆沉」：骤降的修正值使现世部分区域向边境转化。
  • 联合国 成立目的之一：维持现境内部修正值的稳定。

阻止区域间通行的方式#

封闭的手段是源质反应堆：反应堆以辉石为动力，烧掉该区域内的源质 → 该区域源质浓度下降 → 区域修正值回升为正值 → 天然裂隙失去形成条件而闭合。这与天然裂隙"形成于修正值降至 0 的地带"正好是同一原理的反向运用。

封锁一条通路
   ├─ 需要：源质反应堆（以辉石为动力，烧掉区域内的源质，把修正值抬为正值）+ 常驻人力（术士）
   └─ 效果：暂时有效
        └─ 一旦供能中断或人力撤离 → 修正值重新降至 0 → 重新撕开
             └─ 而维稳网是无中心结构 → 总有人先撤

封路与「延缓现世沉入旧域」在抢同一批燃料。 源质反应堆 本就是各势力对终末之环 逆向工程、用于延缓现世沉没的造物——把它调去封路，意味着维稳与续命是同一个预算。

因此通路的封锁不是没人管，而是管不过来。

通路类型#

通路形态稳定性主要使用者
天然裂隙修正值降至 0 的地带自然形成的接缝低，位置漂移奇幻种、走私者、失控的扭曲者
人工门径以炼金学与辉石能量维持的定向通路高，但昂贵且需持续供能各国官方、前先锋守望干员、正规术士部队

通行代价#

  1. 修正值冲击：跨越接缝时，个体承受的源质浓度骤变。按能力体系的阶段，普通人穿越天然裂隙的扭曲风险极高，术士则视环阶而定——这正是"抗性"最实际的意义。
  2. 单向性倾向：向旧域方向通行易、返回难（旧域混乱无序、缺乏稳定坐标）。这也是"任何时代的遗迹皆有可能在旧域内出现"却极少被完整带出的原因。
  3. 人格磨损：长期往返者会出现感知偏移，与高环术士的人格崩溃同源但更慢。
  4. 现世侧代价：私自通行将影响帷幕工程的运转，因此是各国官方的重点打击对象。

主体可通行范围说明

治理现状#

按「各国官方 + 前先锋守望合法术士维稳，对抗非法术士与渗透者」的格局：

  • 各国官方掌握人工门径的审批与供能。
  • 前先锋守望合法术士负责巡查天然裂隙。
  • 非法术士与被旧域注视者则利用天然裂隙走私人员、遗物与情报。

「永久关闭」为什么办不到#

不存在永久关闭通路的手段。 这不是秘密，而是物理上办不到。

接缝不是可以堵死的洞，而是区域修正值降至 0 时自然出现的现象（见上方「通路类型」）。所以要"永久关闭"它，等于要把该区域的修正值永久抬到 0 以上——而修正值取决于游离态源质 的浓度，源质不可开采、不可储运，且广泛分布于世界每一个角落（见 修正值）。

于是只剩一条路：持续燃烧。而一旦停止燃烧，浓度立刻回升，接缝重新撕开。

唯一的成功案例是一件已经失去的遗物：千禧陆沉之前，现世的稳定正是靠 终末之环 唯一一次做到了这件事 —— 而它已经沉入旧域深处。

尚未展开#

  • 源质反应堆的数量与部署成本：源质反应堆烧掉区域内源质、把修正值抬为正值，但现世究竟有多少台反应堆、由谁提供与审批，尚未确立（并与「遗物 由哪一方逆向工程」同题）。

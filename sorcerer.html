术士

核心规则核心规则更新：2026-09-27

原文

【术士】

术士是一切与律法融合后获得源质回路存在的统称。

在融合律法后，术士的体内会形成一种名为“源质回路”的特殊结构，术士对源质的扭曲抗性将会因此增强。

也正因如此，术士可在源质回路中存储源质以供律法优先调用，省略了从环境中吸收源质的过程，使术士能够更高效地施展律法。

当源质回路中的源质消耗殆尽时，术士就需要从环境中重新吸收源质，或直接吸收辉石内部经过高度浓缩的源质来恢复。

可一旦源质储量超过自身当前源质回路的上限，术士便会因无法承受源质的扭曲而发生不可逆的转化。

要点#

  • 统称：一切与律法融合后获得源质回路的存在的统称。
  • 范围：术士不限于人类，也不限于类人种族——凡能与律法融合、并由此获得源质回路者皆在此列，故奇幻种、龙裔 亦可有术士。
  • 位阶：1–9 环，1 环最低、9 环最高。
  • 代价：环的数量越高，稳定自身人格的难度也就越高——因为个体与律法的融合程度越深。
  • 源质回路：融合律法后，术士的体内会形成名为「源质回路」的特殊结构——它正是「术士」这个统称的判据：与律法融合、并因此获得源质回路者，即为术士。回路使术士对源质的扭曲抗性增强，并可在体内提前存储源质供律法优先调用——省略了从环境中吸收源质的过程，因此施展律法更高效。
  • 流转：术士死亡时，赋予其非凡能力的律法会重新转化为碎片，直到它们与新的术士或 遗物 融合（详见 律法）。

核心机制：为什么越高环越难稳定人格#

律法只是一种运用源质扭曲现实的有效手段，高环术士的人格崩溃是因为源质本身对现实具有扭曲性，术士或许相较于普通人而言对源质有着更高的抗性，可一旦源质的浓度过高，其依旧存在扭曲的可能性。

源质（高维能量 · 对现实具有扭曲性）        ← 病因是源质的扭曲性，不是律法
   │
   术士 ──融合──► 律法                        ← 融合是术士之所以为术士的前提
   │                │
   │                └─► 副产物：体内形成「源质回路」
   │                          │
   │                          └─► 扭曲抗性增强 → 可预存源质、可优先调用
   │
   └─ 抗性：术士 > 普通人（相对优势，非免疫）
          │
          └─ 源质浓度超过个体阈值 ──► 扭曲（普通人、术士同样会发生）

注意：律法与术士是不可分离的——源质回路正是融合律法的副产物，没有融合就没有回路，也就没有那份抗性。律法是术士之所以为术士的前提；但它不是病因——病因是源质自身的扭曲性。

三个要点：

  1. 术士之所以强，是因为融合了律法——融合使体内形成「源质回路」，从而能预存并优先调用源质（见上方原文）。

2.高环术士人格崩溃，本质是长期接触源质后，源质对现实（含自身）的扭曲作用累积所致。

  1. 术士比普通人耐受得多，但没有绝对免疫；浓度一旦超过阈值，术士一样扭曲。

环阶的四个阶段#

1–9 环并非平铺的九级台阶，而是四个阶段——个体与律法的关系在其中逐层改变：

物质界（1–3 环）→ 形成界（4–6 环）→ 创造界（7–9 环）→ 原型界（超越 9 环）

前三阶段属于术士，第四个（原型界）不属于。完整表格、原型界的实质、位阶与类别对照，见 能力体系。

「术士」是现代体系的名字#

这个名字属于现代非凡体系。而在它之前，同一类存在被叫作新神——原始非凡体系下的执掌律法者：

体系途径
新神原始非凡体系（混沌时代 ～ 十四世纪末）通过教会向神明献上信仰与忠诚
术士现代非凡体系（复兴时代 起）以炼金学为核心

两者本质是同一类存在，区别只在名称随体系更替而变。详见 新神 · 祂们就是"原始体系下的术士"。

为什么融合越深，人格越不稳#

四个阶段是同一条因果链上的四个刻度：

初步接触律法 → 进一步理解 → 深度融合 → 彻底超越个体性
     │              │            │            │
 人格稳定度高    稳定度中     稳定度低      人格崩解
                                    │
                          以自身为通道调用的源质浓度骤升
                                    │
                        源质本身的扭曲性持续作用于自身

前三个阶段里，融合得越深，个体以自身为通道调用的源质越多，源质本身的扭曲性也就累积得越快——崩溃由此而来，与律法无关。

也就是说：位阶衡量的是"你与律法有多近"，人格的代价衡量的是"你替它承受了多少源质"。

四阶段的人格稳定度曲线见 能力体系 · 为什么融合越深，人格越不稳。

与修正值的关系#

修正值 是衡量源质反应程度的唯一方式，且同时适用于区域与个体——抗性阈值与修正值是同一套标尺，不必另立"耐受上限"单位：

  • 区域修正值低于 0 → 该区域源质浓度过高 → 区域内一切存在面临扭曲风险（对应第三次冲击"无数人因修正值突破 0 的界限而扭曲"）。
  • 个体修正值低于 0 → 该个体承受的源质浓度已超阈值 → 扭曲。
  • 高环术士的人格崩溃 → 同一条曲线的极端表现：以自身为通道长期高浓度暴露。

也就是说：区域的无序与术士的疯狂，是同一种病在不同尺度上的表现。

律法熔断#

术士可以完全解放自身律法，进入"律法熔断"状态，以结束后一段时间内无法使用律法为代价换取短暂的实力提升，但进入"律法熔断"状态的时间越长，后续恢复所需要的时间便越长，严重时甚至将造成术士本身的死亡。

要点#

  • 性质：术士主动完全解放自身律法，进入「律法熔断」状态。
  • 收益：换取短暂的实力提升。
  • 代价：熔断结束后，一段时间内无法使用律法。
  • 递进：进入熔断的时间越长 → 后续恢复所需时间越长 → 严重时造成术士本身的死亡。
  • 适用：所有环阶的术士皆可进入熔断状态。

熔断针对的是「术士与律法的关系」#

术士是一切与律法融合后获得源质回路存在的统称——「与律法融合」正是这个统称的定义所在。因此原文把代价定在律法本身（"一段时间内无法使用律法"），而不是定在源质抗性上：

平时：术士 ──融合──► 律法 ──调用──► 源质 ──扭曲──► 现实

熔断：术士 ══完全解放══► 律法（全开）──► 短暂的实力提升
        │
        └─► 结束后：律法在一段时间内无法被使用
              └─► 熔断越久 → 恢复越久 → 严重时致死

也就是说：熔断是"把律法开到全满"，而不是"让源质灌得更猛"。 因此它是一条与人格崩解并列、而非从属的机制。

与人格崩解的区别#

高环术士的人格崩解律法熔断
起因长期、大剂量调用源质，源质自身的扭曲性不断累积术士主动解放自身律法
代价形态人格崩解，仅剩本能的神性主导熔断后一段时间无法使用律法
是否可逆不可逆（见 能力体系）可恢复——但熔断越久、恢复越久，严重时致死
谁会碰上融合越深越容易，高环术士最先崩解所有环阶皆可主动进入

一句话：崩解衡量的是「你替源质承受了多少」，熔断衡量的是「你把律法开到了多满」。

体系两阶段#

阶段时代获取非凡的途径
原始非凡体系混沌时代通过教会向神明献上信仰与忠诚，以换取通往非凡的资格
现代非凡体系复兴时代 起以 炼金学 为核心；术士与国家势力深度绑定

术士在现世社会的处境#

明面：按「是否在契约之内」分类。

  • 合法术士受信任并被部署——各国官方以国家契约绑定术士，手里握着门径审批、辉石产地与术士部署。
  • 非法术士被归为不稳定因素——官方用的是行为分类而非身份分类（时间线 记有「仅因行为模式相似而被官方归为一类」）。

暗面：创造界另有登记与预案。

  • 形成界是现世骨干（术语索引 记作"绝大部分精英术士"），被完全信任；
  • 创造界——新神、旧王 与极少数传奇术士所在的那一界——人格稳定度低（见 能力体系），因此各国超凡部门对这几个人另有一套登记、隔离与"预案"，心照不宣。
  • 数量少（原文说是"极少数"）反而使这套做法可行。

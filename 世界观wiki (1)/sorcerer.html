术士

原文

【术士】

术士是一切执掌律法类人生物的统称。

其位阶被划分为1-9环，1环为最低阶，9环为最高阶，环的数量越高，稳定自身人格的难度也就越高。

要点#

  • 统称：一切执掌 律法 的类人生物的统称。
  • 范围：术士是类人生物的位阶体系——不限于人类。凡形态近似人类的种族皆在此列，故奇幻种、龙裔 亦可有术士。
  • 位阶：1–9 环，1 环最低、9 环最高。
  • 代价：环的数量越高，稳定自身人格的难度也就越高——因为个体与律法的融合程度越深。
  • 流转：术士死亡时，赋予其非凡能力的律法会脱离主体，直到新的 遗物 形成或被其他术士融合（详见 律法）。

核心机制：为什么越高环越难稳定人格#

律法只是一种运用源质扭曲现实的有效手段，高环术士的人格崩溃是因为源质本身对现实具有扭曲性，术士或许相较于普通人而言对源质有着更高的抗性，可一旦源质的浓度过高，其依旧存在畸变的可能性。

源质（高维能量 · 对现实具有扭曲性）        ← 这是根因，不是律法
   │
   ├─ 律法 = 运用源质扭曲现实的「有效手段」  ← 术士是运用者，不是承载者
   │
   └─ 抗性：术士 > 普通人（相对优势，非免疫）
          │
          └─ 源质浓度超过个体阈值 ──► 畸变（普通人、术士同样会发生）

三个要点：

  1. 律法是手段，不是病因。 术士之所以强，是因为掌握了调用源质的方法，而非因为体内寄宿着律法。
  2. 崩溃的根因是源质自身的扭曲性。 高环术士人格崩溃，本质是长期、大剂量调用源质后，源质对现实（含自身）的扭曲作用累积所致。
  3. 抗性是相对值。 术士比普通人耐受得多，但没有绝对免疫；浓度一旦超过阈值，术士一样畸变。

环阶的四个阶段#

1–9 环并非平铺的九级台阶，而是四个阶段——个体与律法的关系在其中逐层改变：

物质界（1–3 环）→ 形成界（4–6 环）→ 创造界（7–9 环）→ 原型界（超越 9 环）

前三阶段属于术士，第四个（原型界）不属于。完整表格、原型界的实质、位阶与类别对照，见 能力体系。

「术士」是现代体系的名字#

这个名字属于现代非凡体系。而在它之前，同一类存在被叫作新神——原始非凡体系下的执掌律法者：

体系途径
新神原始非凡体系（混沌时代 ～ 十四世纪末）通过教会向神明献上信仰与忠诚
术士现代非凡体系（复兴时代 起）以炼金学为核心

两者本质是同一类存在，区别只在名称随体系更替而变。详见 新神 · 祂们就是"原始体系下的术士"。

为什么融合越深，人格越不稳#

四个阶段是同一条因果链上的四个刻度：

初步接触律法 → 进一步理解 → 深度融合 → 彻底超越个体性
     │              │            │            │
 人格稳定度高    稳定度中     稳定度低      人格崩解
                                    │
                          以自身为通道调用的源质浓度骤升
                                    │
                        源质本身的扭曲性持续作用于自身

前三个阶段里，融合得越深，个体以自身为通道调用的源质越多，源质本身的扭曲性也就累积得越快——崩溃由此而来，与律法无关。

也就是说：位阶衡量的是"你与律法有多近"，人格的代价衡量的是"你替它承受了多少源质"。

与修正值的关系#

修正值 是衡量源质反应程度的唯一方式，且同时适用于区域与个体——抗性阈值与修正值是同一套标尺，不必另立"耐受上限"单位：

  • 区域修正值低于 0 → 该区域源质浓度过高 → 区域内一切存在面临畸变风险（对应第三次冲击"无数人因突发的源质畸变而扭曲"）。
  • 个体修正值低于 0 → 该个体承受的源质浓度已超阈值 → 畸变。
  • 高环术士的人格崩溃 → 同一条曲线的极端表现：以自身为通道长期高浓度暴露。

也就是说：区域的无序与术士的疯狂，是同一种病在不同尺度上的表现。

阶段时代获取非凡的途径
